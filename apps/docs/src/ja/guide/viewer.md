# ビューアー

小さな文字や長いレシートは、画面上では一目で読みにくいものです。ビューアーは読み込み時に画像をフィットさせ、どこでもズームできるようにします。

<Demo src="/samples/receipt.jpg" alt="レシート" :editable="false" />

## ズームと移動

| 操作                         | マウスとトラックパッド                 | タッチ       | キーボード |
| ---------------------------- | -------------------------------------- | ------------ | ---------- |
| ズーム                       | ホイール、またはトラックパッドでピンチ | ピンチ       | `+` と `-` |
| 移動                         | ドラッグ                               | ドラッグ     | 矢印キー   |
| フィットと 100% を切り替える | ダブルクリック                         | ダブルタップ |            |
| 画像全体をフィット           |                                        |              | `0`        |

キーボードは、ビューアーにフォーカスがあるときに使えます。ピンチでは指と指の間の点を中心にズームします。タッチスクリーンでは、画像がフィットしている間は 1 本指でページがスクロールし、ズームすると画像が移動します。

ズームの範囲は、画像全体のフィット（小さな画像では 100%）から 800% までです。収まる画像は中央に置かれ、はみ出す画像は端まで移動できます。

読み込み時、画像はビューアー全体にフィットし、ユーザーが手動でズームするまでは、ビューアーのサイズが変わってもフィットを保ちます。

長いページでは、ホイールでページがスクロールせずに画像がズームしてしまいます。その場合は `wheelZoom: false` にしてください。ボタン、キーボード、タッチスクリーンでのピンチは引き続きズームできます。

## ツールバー

ツールバーはビューアーの右側にあり、ビューアーの高さが足りないときはスクロールします。編集中は非表示になるため、「切り抜き」や「傾き補正」の角を隠すことはありません。

| ボタン                             | 動作                                                                |
| ---------------------------------- | ------------------------------------------------------------------- |
| 「編集」                           | [編集モード](./editing)を始めます。`editable: false` では非表示です |
| 「拡大」「縮小」                   | 中心を基準に 1 段階ズームします                                     |
| 「幅に合わせる」「高さに合わせる」 | 幅（長い文書に便利）または高さをフィットさせます                    |
| 「左に回転」「右に回転」           | 読み取り専用のビューアーでのみ、表示中の画像を回転します            |
| 「ダウンロード」                   | `download: true` のときのみ、表示中の画像を保存します               |

`toolbar: false` にするとツールバーと編集バーが非表示になり、[メソッド](../reference/methods)で独自の操作を作れます。

## 読み取り専用のビューアー {#read-only}

`editable: false` にすると「編集」ボタンがなくなり、ツールバーに画像を回転する 2 つのボタンが加わります。この回転は表示だけを変え、何も保存されません。記録の添付ファイルなど、読んでほしいが変更されたくない文書に使います。

:::tabs key:framework
== JavaScript

```ts
const pic = new PaperPic(container, {
  src: '/receipt.jpg',
  alt: 'レシート',
  editable: false,
})
```

== Vue

```vue
<PaperPic src="/receipt.jpg" alt="レシート" :editable="false" />
```

== React

```tsx
<PaperPic src="/receipt.jpg" alt="レシート" editable={false} />
```

:::

## コードから表示を操作する

[`zoomIn()`](../reference/methods#zoomin)、[`zoomOut()`](../reference/methods#zoomout)、[`zoomTo()`](../reference/methods#zoomto)、[`fit()`](../reference/methods#fit) の各メソッドはボタンと同じ動作をし、[`getState()`](../reference/methods#getstate) で現在のズームとフィットがわかります。

```ts
pic.fit('width')
pic.zoomTo(2)

const { zoom, fit } = pic.getState()
```
