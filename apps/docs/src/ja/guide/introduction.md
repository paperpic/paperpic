# PaperPic とは

文書の写真は、傾いていたり、影があったり、背景が多く写っていたりします。PaperPic はそうした写真をズームできるビューアーで表示し、スキャナーアプリのように、アプリが保存する前に 1 枚ずつ傾きを補正してクリーンアップできるようにします。

## できること

- **表示。** ボタン、ホイール、ピンチでのズーム、画像の移動、画像全体・幅・高さへのフィット。読み取り専用のビューアーでは画像の回転もできます。
- **編集。** 編集モードでは、切り抜き、斜めから撮った写真の傾き補正、回転、反転、明るさとコントラストの調整、文書の白黒へのクリーンアップができます。変更は、ユーザーが適用するまですべて元に戻せます。
- **受け渡し。** 適用すると結果がフル解像度で計算され、`Blob` としてコードに渡されます。ダウンロードボタンで保存することもできます。

どの処理も、ユーザーが求めたときにだけ行われます。写真が勝手に変わることはありません。

## できないこと

- 何もアップロードしません。結果をどうするかはアプリが決めます。
- PDF ファイルは開けません。開けるのは画像だけです。
- 文書の輪郭を自動では検出しません。ユーザーが角をドラッグします。

## パッケージ

| パッケージ        | 使う環境                                      |
| ----------------- | --------------------------------------------- |
| `@paperpic/core`  | 素の JavaScript、またはあらゆるフレームワーク |
| `@paperpic/vue`   | Vue 3.5 以降                                  |
| `@paperpic/react` | React 19 以降                                 |

3 つとも同じオプション、イベント、メソッドを持ち、コアには実行時の依存関係がありません。編集は Web Worker で行われるため、大きな写真でもページの応答性が保たれます。

## 試してみる

[プレイグラウンド](../playground)では、サンプルのレシートや、ブラウザーの外に出ることのない自分の写真を編集できます。PaperPic をアプリに組み込むには、[はじめに](./getting-started)に進んでください。
