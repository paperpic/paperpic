# 回転と反転

スマートフォンは文書の写真を横向きや逆さまに保存しがちで、スキャンが鏡像になることもあります。「左に回転」と「反転」は向きを直し、画像のほかの部分はそのままにします。

## 回転

編集バーの「左に回転」は、写真ギャラリーと同じように画像を反時計回りに 90 度回転します。2 回押すと 180 度、3 回押すと時計回りに 90 度になります。

回転は変更の一つです。「元に戻す」で取り消せ、「適用」で確定します。4 回回転すると元の向きに戻り、適用するものはなくなります。

コードからは、[`rotate()`](../../reference/methods#rotate) に `1` を渡すと時計回り、`-1` を渡すと反時計回りに回転します。

```ts
pic.rotate(1)
pic.rotate(-1)
```

## 反転

「反転」は、表示されている向きのまま画像を左右に反転します。90 度回転したあとでも、画面上で左右に反転します。画像を上下逆にするには、反転してから 2 回回転します。

打ち消し合う反転と回転は、適用するものを残しません。コードからは [`flip()`](../../reference/methods#flip) を呼び出します。

## 読み取り専用のビューアー

[`editable: false`](../viewer#read-only) では、ツールバーに「左に回転」と「右に回転」のボタンがあります。表示中の画像を回すだけで、何も保存されず、`apply` イベントも発生しません。[`rotate()`](../../reference/methods#rotate) はコードから同じことをします。読み取り専用のビューアーに「反転」はありません。

## Id

[`tools`](../../reference/options#tools) オプションでは、「左に回転」が `'rotate'`、「反転」が `'flip'` です。
