# クリーンアップ

紙に書かれた文字は白黒がいちばん読みやすいのですが、写真には影やむらのある光、灰色がかった紙が写ります。「クリーンアップ」は各ピクセルを周囲と比べてインクか紙かを判定するため、影や光のむらが消え、文字はくっきり残ります。API での id は `threshold` です。

<Demo src="/samples/receipt.jpg" alt="レシート" :tools="['perspective', 'threshold']" />

まずレシートの傾きを補正し、それからクリーンアップしてください。

## 使い方

1. 「編集」、続いて「クリーンアップ」を押します。プレビューが白黒になり、「感度」のスライダーが表示されます。
2. スライダーをドラッグします。感度を上げると暗くなるピクセルが増え、薄い文字やかすれた文字を拾えます。感度を下げると、裏から透けた文字のないきれいなページになります。スライダーを離すと変更が 1 つ残ります。
3. もう一度「クリーンアップ」を押すとオフになります。

「クリーンアップ」は常にほかの変更のあとに適用されます。「切り抜き」と「傾き補正」では、クリーンアップしていない画像が表示されます。クリーンアップしたページでは紙の端を見つけにくいためです。

## 柔らかさ

[`softness`](../../reference/options#softness) は、「クリーンアップ」が文字の輪郭に残すグレーの量を 0 から 1 で指定し、デフォルトは 0.25 です。少しグレーが残ると輪郭がなめらかになり、小さな文字が読みやすくなります。`0` にすると厳密な白黒になり、ファイルは小さくなりますが細い線が途切れます。

## 結果の形式

クリーンアップした画像は PNG になります。JPEG だとくっきりした輪郭の周りにノイズが出るためです。[`output`](../../reference/options#output) オプションで別の形式を選べます。

## コードから使う

[`setThreshold()`](../../reference/methods#setthreshold) は「クリーンアップ」のオンとオフを切り替え、感度を 0 から 1 で設定します。デフォルトは 0.5 です。[`getState()`](../../reference/methods#getstate) は両方を `threshold` で返します。

```ts
pic.edit()
pic.setThreshold({ enabled: true, sensitivity: 0.6 })
```
