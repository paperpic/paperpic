# クリーンアップ

「クリーンアップ」は画像の仕上げを選びます。元の色調、グレー、白黒のどれかです。API での id は `finish` です。

紙に書かれた文字は白黒がいちばん読みやすいのですが、写真には影やむらのある光、灰色がかった紙が写ります。白黒は各ピクセルを周囲と比べてインクか紙かを判断するので、影や光のむらが消え、文字はくっきり残ります。グレーはすべての色調を残して色だけを取り除くので、白黒では失われる写真や印のある文書に向いています。

まずレシートの傾きを補正し、それからクリーンアップしてください。

## 使い方

1. 「編集」を押し、次に「クリーンアップ」を押します。ツールの代わりにパネルが表示され、「オリジナル」「グレー」「白黒」の 3 つの仕上げが並びます。白黒で開くので、プレビューが白黒になり、「感度」の目盛りが使えます。
2. 目盛りをドラッグします。感度を上げるとより多くのピクセルが暗くなり、薄い文字やかすれた文字が戻ります。感度を下げると、裏から透けた印刷のない、すっきりしたページになります。
3. グレーの画像にするなら「グレー」を、写真の色調のままにするなら「オリジナル」を選びます。目盛りは白黒のときだけ使えます。
4. 「完了」を押すと 1 つの変更として残り、「このツールをキャンセル」を押すと画像は元のままです。

「クリーンアップ」がすでに変更になっていれば、その仕上げのまま開きます。オフにするには「オリジナル」を選びます。そのあとの変更は残ります。一方、「元に戻す」ではそれらの変更も消えます。

「クリーンアップ」は常にほかの変更のあとに適用されます。「切り抜き」は仕上げを付けた、仕上がりどおりの画像を表示します。「傾き補正」は白黒なしで表示します。クリーンアップしたページでは紙の端が見つけにくいためです。グレーはそのまま残ります。

[「調整」](./adjust)はそのあとに来るグレーとは一緒に使えますが、独自の色調を持つ白黒のときは使えません。

## 柔らかさ

[`softness`](../../reference/options#softness) は、白黒が文字の端に残すグレーの量を 0 から 1 で決めます。既定値は 0.25 です。少しのグレーが端をなめらかにし、小さな文字を読みやすくします。厳密な白黒にするには `0` を使います。ファイルは小さくなりますが、細い線が途切れます。

## 結果の形式

白黒の画像は PNG になります。JPEG ではくっきりした端のまわりにノイズが出るためです。グレーの画像は元の形式のままです。[`output`](../../reference/options#output) オプションで別の形式を選べます。

## コードから使う

[`setFinish()`](../../reference/methods#setfinish) は仕上げを `'original'`、`'gray'`、白黒の `'mono'` から選び、白黒の感度を 0 から 1 で設定します。既定値は 0.5 です。[`getState()`](../../reference/methods#getstate) は両方を `finish` で返します。

```ts
pic.edit()
pic.setFinish({ mode: 'mono', sensitivity: 0.6 })
```

「クリーンアップ」が開いている間は、`setFinish()` がそのパネルの表示を変え、[`confirmTool()`](../../reference/methods#confirmtool) がそれを 1 つの変更として残します。
