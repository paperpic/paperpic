# 傾き補正

斜めから撮った文書は台形に見えます。奥の辺が短くなり、文字が傾きます。「傾き補正」は、スキャンしたような平らな長方形のページに戻します。API での id は `perspective` です。

<Demo src="/samples/receipt.jpg" alt="レシート" :tools="['perspective']" />

## 使い方

1. 「編集」、続いて「傾き補正」を押します。角ごとにハンドルが表示されます。ビューアーが文書を[見つける](#finding-the-document)と、文書の上に表示されます。
2. ずれているハンドルを文書の角にドラッグします。パネルのズームボタンで拡大すると正確に置けます。
3. 用紙がわかっている場合は、[サイズ](#paper-size)を「A4」「レター」「カード」から選びます。「自動」は推定します。
4. 「完了」または `Enter` を押します。ビューアーには、4 つの角で切り抜かれた平らなページが表示されます。「完了」は、ビューアーが文書を見つけるか、角を動かすまで押せません。

ハンドルは[「切り抜き」](./crop)と同じように動きます。タッチスクリーンではルーペが出て、ドラッグの代わりに押してからタップすることもでき、キーボードでは Tab と矢印キーを使います。4 つの角は常に凸形を保つため、ページは必ず平らにできます。

「傾き補正」は[「クリーンアップ」](./clean-up)の白黒なしで写真を表示します。クリーンアップしたページでは紙の端を見つけにくいためです。「完了」を押すと白黒に戻り、グレーはそのまま残ります。

## 文書を見つける {#finding-the-document}

「傾き補正」を開くと、ビューアーが写真の中の文書を探し、4 つの角をその上に置きます。そのため「完了」をすぐに押せます。探す処理はブラウザーの中で一瞬で終わり、「完了」を押すまで何も変わりません。

ビューアーが提案するのは、十分に確信があるものだけです。紙とテーブルの見分けがつきにくい場合や、写真に文書がない場合、角は画像の内側から始まり、ユーザーの操作を待ちます。ユーザーがすでに触れた角が、勝手に動くことはありません。

## 用紙サイズ {#paper-size}

「傾き補正」のパネルには用紙サイズがあり、結果をその用紙の正確な縦横比にします。

| 選択肢 | 縦横比                                                                             |
| ------ | ---------------------------------------------------------------------------------- |
| 自動   | [`aspectRatio`](../../reference/options#aspectratio)、なければ[推定](#proportions) |
| A4     | 210 × 297 mm。A3 と A5 も同じです                                                  |
| レター | 8.5 × 11 インチ、US レター                                                         |
| カード | 85.6 × 53.98 mm、身分証や銀行カード                                                |

サイズが決めるのは縦横比だけです。角は動かしません。縦向きか横向きかは角の位置に従うので、向きを選ぶ必要はありません。文書と違うサイズを選ぶと文書がゆがむため、「傾き補正」は開くたびに「自動」から始まります。

4 つの角が画像の角にある場合、「自動」は何も変えず、サイズを選ぶと画像全体がその用紙の縦横比になります。

## 縦横比 {#proportions}

写真からはページの本当の形がわからないため、「傾き補正」は写真の中の角の位置から縦横比を推定します。ふつうの距離から撮った写真には向いていますが、正確にはなりません。

推定には元の写真が使われます。同じ編集の中で切り抜きや回転をしたあとでも同じです。ユーザーが適用すると、その結果が新しい写真として扱われるため、傾き補正は適用の前に行ってください。

文書がわかっている場合は、[`aspectRatio`](../../reference/options#aspectratio) に幅を高さで割った値を指定すると、結果がその縦横比になります。

:::tabs key:framework
== JavaScript

```ts
const pic = new PaperPic(container, {
  src: '/invoice.jpg',
  aspectRatio: 210 / 297,
})
```

== Vue

```vue
<PaperPic src="/invoice.jpg" :aspect-ratio="210 / 297" />
```

== React

```tsx
<PaperPic src="/invoice.jpg" aspectRatio={210 / 297} />
```

:::

| 文書                   | `aspectRatio`  |
| ---------------------- | -------------- |
| A4 用紙（縦）          | `210 / 297`    |
| US レター用紙（縦）    | `8.5 / 11`     |
| 身分証明書カード（横） | `85.6 / 53.98` |

横向きの用紙では、`297 / 210` のように数値を入れ替えます。縦横比は画面に表示されているページに適用されるので、写真が横向きなら、補正の前に[「左に回転」](./rotate-and-flip)で回してください。

## 写真からはみ出した角

文書の角が写真の外に出てしまうことがあります。ハンドルは画像の内側にとどまるため、そのハンドルは写真の端に、内容が残る側の文書の辺に沿って置いてください。最後の数行がわずかに傾き、縦横比の推定も悪くなりますが、[`aspectRatio`](../../reference/options#aspectratio) で補正できます。

[プレイグラウンド](../../playground)には、角が欠けたサンプルのレシートがあり、試すことができます。

## コードから使う

「傾き補正」は [`openTool('perspective')`](../../reference/methods#opentool) で開き、[`confirmTool()`](../../reference/methods#confirmtool) か [`cancelTool()`](../../reference/methods#canceltool) で閉じます。

```ts
pic.edit()
pic.openTool('perspective')
pic.setPaper({ size: 'a4' })

// あとで、自前のボタンから
pic.confirmTool()
```

ツールが開いている間に [`setPaper()`](../../reference/methods#setpaper) で用紙サイズを選びます。`confirmTool()` は、ビューアーが文書を見つけるか、角が動くまで待ちます。いつ確定できるかは[状態](../../reference/state)の `canConfirm` が示します。
