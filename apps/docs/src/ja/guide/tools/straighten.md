# 傾き補正

斜めから撮った文書は台形に見えます。奥の辺が短くなり、文字が傾きます。「傾き補正」は、スキャンしたような平らな長方形のページに戻します。API での id は `perspective` です。

<Demo src="/samples/receipt.jpg" alt="レシート" :tools="['perspective']" />

## 使い方

1. 「編集」、続いて「傾き補正」を押します。角ごとにハンドルが表示されます。
2. 各ハンドルを文書の角にドラッグします。パネルのズームボタンで拡大すると正確に置けます。
3. 「完了」または `Enter` を押します。ビューアーには、4 つの角で切り抜かれた平らなページが表示されます。

ハンドルは[「切り抜き」](./crop)と同じように動きます。タッチスクリーンではルーペが出て、ドラッグの代わりに押してからタップすることもでき、キーボードでは Tab と矢印キーを使います。4 つの角は常に凸形を保つため、ページは必ず平らにできます。

「傾き補正」は[「クリーンアップ」](./clean-up)なしの写真を表示します。クリーンアップしたページでは紙の端を見つけにくいためです。「完了」を押すと、クリーンアップが再び適用されます。

## 縦横比

写真からはページの本当の形がわからないため、「傾き補正」は写真の中の角の位置から縦横比を推定します。ふつうの距離から撮った写真には向いていますが、正確にはなりません。

推定には元の写真が使われます。同じ編集の中で切り抜きや回転をしたあとでも同じです。ユーザーが適用すると、その結果が新しい写真として扱われるため、傾き補正は適用の前に行ってください。

文書がわかっている場合は、[`aspectRatio`](../../reference/options#aspectratio) に幅を高さで割った値を指定すると、結果がその縦横比になります。

:::tabs key:framework
== JavaScript

```ts
const pic = new PaperPic(container, {
  src: '/invoice.jpg',
  aspectRatio: 210 / 297,
})
```

== Vue

```vue
<PaperPic src="/invoice.jpg" :aspect-ratio="210 / 297" />
```

== React

```tsx
<PaperPic src="/invoice.jpg" aspectRatio={210 / 297} />
```

:::

| 文書                   | `aspectRatio`  |
| ---------------------- | -------------- |
| A4 用紙（縦）          | `210 / 297`    |
| US レター用紙（縦）    | `8.5 / 11`     |
| 身分証明書カード（横） | `85.6 / 53.98` |

横向きの用紙では、`297 / 210` のように数値を入れ替えます。

## 写真からはみ出した角

文書の角が写真の外に出てしまうことがあります。ハンドルは画像の内側にとどまるため、そのハンドルは写真の端に、内容が残る側の文書の辺に沿って置いてください。最後の数行がわずかに傾き、縦横比の推定も悪くなりますが、[`aspectRatio`](../../reference/options#aspectratio) で補正できます。

[プレイグラウンド](../../playground)には、角が欠けたサンプルのレシートがあり、試すことができます。

## コードから使う

「傾き補正」は [`openTool('perspective')`](../../reference/methods#opentool) で開き、[`confirmTool()`](../../reference/methods#confirmtool) か [`cancelTool()`](../../reference/methods#canceltool) で閉じます。

```ts
pic.edit()
pic.openTool('perspective')

// あとで、自前のボタンから
pic.confirmTool()
```
