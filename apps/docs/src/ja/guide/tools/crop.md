# 切り抜き

文書の写真には、机や手、周りの別の紙が写り込みがちです。「切り抜き」は文書を含む長方形だけを残し、それ以外を取り除きます。

## 使い方

1. 「編集」、続いて「切り抜き」を押します。画像の内側に、各角にハンドルの付いた長方形が表示されます。
2. 長方形が文書を囲むまで角をドラッグします。ズームボタンは使えるままなので、拡大して正確に置けます。
3. 「完了」または `Enter` で、切り抜きが変更に加わります。「このツールをキャンセル」または `Esc` で、何も変えずに「切り抜き」を閉じます。

切り抜きはほかの変更と同じです。「元に戻す」で取り消せ、「適用」で確定します。

## 角のハンドル

- ハンドルは画像の内側にとどまり、長方形が裏返ることはありません。
- タッチスクリーンでは、角をドラッグしている間、指の下の領域をルーペが表示するため、角の位置が指で隠れません。
- ドラッグしなくても、ハンドルを押してから角の移動先をタップできます。それまでハンドルは強調表示され、`Esc` で選択を解除します。
- キーボードでは Tab でハンドルを移り、矢印キーでフォーカスのあるハンドルを画面の 1 ピクセル、Shift を押しながらなら 10 ピクセル動かします。スクリーンリーダーは移動のたびに読み上げます。

## 「切り抜き」か「傾き補正」か

「切り抜き」は長方形をそのまま残します。斜めから撮った写真では文書が台形に見え、長方形では合いません。そうした写真には[「傾き補正」](./straighten)を使ってください。角を 1 つずつ動かしてページを平らにします。

## コードから使う

「切り抜き」はデフォルトで編集バーにあり、[`tools`](../../reference/options#tools) での id は `'crop'` です。`toolbar: false` のときは [`openTool()`](../../reference/methods#opentool) で開き、[`confirmTool()`](../../reference/methods#confirmtool) か [`cancelTool()`](../../reference/methods#canceltool) で閉じます。

```ts
pic.edit()
pic.openTool('crop')

// あとで、自前のボタンから
pic.confirmTool()
```
