# 塗りつぶし

文書の写真には、口座番号、署名、背景の顔など、見せたくないものが写り込むことがあります。「塗りつぶし」はまっすぐな、または傾いた長方形を黒または白で完全に覆い、その下にあったものは結果に残りません。

<Demo src="/samples/receipt.jpg" alt="レシート" :tools="['redact']" />

## 使い方

1. 「編集」、続いて「塗りつぶし」を押します。画像の中央に、各角にハンドルの付いた帯が表示されます。
2. 隠す部分に領域を描きます。画像のどこでも、帯の上でも、領域の角から反対側の角までドラッグします。その後は、領域をドラッグすると動かせ、上にあるハンドルで回転させると傾いた文字の行に合わせられ、角をドラッグすると大きさが変わります。領域は半透明で色を表示するので、正しい文字の上に置けます。
3. パネルで「黒」か「白」を選びます。
4. 「完了」か `Enter` を押すと、領域が変更に加わります。「このツールをキャンセル」か `Esc` を押すと、何も変えずに「塗りつぶし」を閉じます。

描けるのは領域を配置するまでです。領域を描く、動かす、回転させる、大きさを変えるのいずれかをすると、画像のほかの部分のドラッグは再び画像の移動になり、領域が誤って置き換わることはありません。それまでは、ズームした画像を 2 本の指で、または画像にフォーカスがある間は矢印キーで移動できます。ドラッグしない場合は、帯がそのまま領域になります。キーボードで動かすか、帯を押してから移動先をタップします。

「完了」を押すたびに領域が 1 つ加わります。別の部分を覆うには「塗りつぶし」をもう一度開きます。「元に戻す」を押すと最後の領域が取り除かれ、色は次の領域にも引き継がれます。角のハンドルは「[切り抜き](./crop)」と同じく、ドラッグ、ハンドルを押してから移動先をタップ、キーボードで操作できます。領域の上のハンドルでは、矢印キーで 1 度、Shift を押すと 10 度回転します。ドラッグ中は水平に吸着します。

## 保証されること {#guarantees}

- 領域はほかのすべての変更の後に塗られるので、「調整」や「クリーンアップ」で黒や白が薄くなることはありません。
- 領域は後の変更に従います。回転、反転、切り抜きでは画像と一緒に動き、「傾き補正」ではページと一緒に変形します。
- 縁が一部でも触れるピクセルはすべて覆い、透明な PNG でも不透明です。
- 変更を適用すると、領域は不透明なピクセルとして結果に書き込まれるので、ファイルには覆われた内容が何も残りません。

変更を適用するまでは元画像が保持されるので、「元に戻す」で領域の下の内容が戻ります。共有するのは必ず適用後の結果にし、元画像は共有しないでください。

## コードから使う

「塗りつぶし」は既定で編集バーにあり、[`tools`](../../reference/options#tools) での id は `'redact'` です。`toolbar: false` のときは、[`openTool()`](../../reference/methods#opentool) で開き、[`setRedaction()`](../../reference/methods#setredaction) で色を選び、[`confirmTool()`](../../reference/methods#confirmtool) か [`cancelTool()`](../../reference/methods#canceltool) で閉じます。

```ts
pic.edit()
pic.openTool('redact')
pic.setRedaction({ color: 'white' })

// 後で、独自のボタンから
pic.confirmTool()
```

[状態](../../reference/state)の `redaction` が使用中の色を持ちます。
