# 調整

暗い場所で撮った写真は、暗く、あるいはくすんで写ります。「調整」は色を保ったまま明るさとコントラストを変えます。カラーの書類や写真など、白黒にしたくない文書に使います。

## 使い方

1. 「編集」、続いて「調整」を押します。編集バーに「明るさ」と「コントラスト」の 2 つのスライダーが表示されます。
2. スライダーをドラッグします。ドラッグ中にプレビューが変わり、離すと変更が 1 つ残ります。「元に戻す」で取り消せます。
3. もう一度「調整」を押すとスライダーが隠れます。

各スライダーの中央は画像をそのままにし、中央に戻したスライダーは変更に数えません。スクリーンリーダーは「明るさ +30」のように、-100 から 100 の値を読み上げます。

「調整」はほかの変更のあとに適用されるため、「切り抜き」と「傾き補正」では調整後の画像が表示されます。

## 「調整」か「クリーンアップ」か

| 「調整」                     | [「クリーンアップ」](./clean-up) |
| ---------------------------- | -------------------------------- |
| 色とグレーを保つ             | 文書を白黒にする                 |
| カラーの書類、印鑑、写真向け | 紙に書かれた文字向け             |
| 元画像の形式を保つ           | PNG になる                       |

「クリーンアップ」がオンの間、「調整」は使えません。クリーンアップした文書には独自の階調があるためです。

## コードから使う

[`setAdjustments()`](../../reference/methods#setadjustments) は -1 から 1 の値を受け取り、0 は変更なしです。[`getState()`](../../reference/methods#getstate) は `adjustments` で値を返します。

```ts
pic.edit()
pic.setAdjustments({ brightness: 0.2, contrast: 0.3 })
```

[`tools`](../../reference/options#tools) オプションでは、「調整」は `'adjust'` です。
