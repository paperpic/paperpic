# アクセシビリティ

文書を読んだり直したりするのに、マウス、指、キーボード、スクリーンリーダーが使われます。PaperPic は WCAG 2.2 AA を目標にしており、ほとんどの対応は組み込み済みです。このページでは、PaperPic が行うことと、アプリが追加すべきことを説明します。

## アプリが用意するもの

- **説明。** 「11 月 5 日のレシート」のように [`alt`](../reference/options#alt) を渡します。スクリーンリーダーは画像の名前として読み上げます。
- **ユーザーの言語のテキスト。** スクリーンリーダーはボタンと変化を読み上げるため、[`labels`](./labels) で翻訳してください。
- **独自の操作がある場合はその対応。** `toolbar: false` では、作成したボタンが組み込みのボタンの代わりになるため、独自の名前とキーボード操作が必要です。
- **見えるフォーカス。** CSS でビューアーのフォーカスの輪郭を隠さないでください。

## キーボード

ビューアーにフォーカスがあるとき:

| キー                           | 操作                                               |
| ------------------------------ | -------------------------------------------------- |
| `+` と `-`                     | 拡大と縮小                                         |
| 矢印キー                       | 移動                                               |
| `0`                            | 画像全体をフィット                                 |
| `Ctrl+Z`                       | 元に戻す                                           |
| `Ctrl+Shift+Z` または `Ctrl+Y` | やり直す                                           |
| `Enter`                        | 開いているツールを確定、なければ変更を適用         |
| `Esc`                          | 開いているツールを閉じる、なければ変更をキャンセル |

macOS では `Cmd` が `Ctrl` と同じ働きをします。変更をキャンセルする前に、`Esc` は確認を求めます。`toolbar: false` では、その判断をあなたのインターフェースに任せます。

- **ツールバーと編集バー。** Tab で各バーに移り、バーの中では矢印キーでボタンを移動し、`Home` と `End` で最初と最後のボタンに移ります。
- **角のハンドル。** 「切り抜き」か「傾き補正」が開いているとき、Tab でハンドルを移り、矢印キーでフォーカスのあるハンドルを画面の 1 ピクセル、Shift を押しながらなら 10 ピクセル動かします。
- **スライダー。** 矢印キーで「調整」と「クリーンアップ」のスライダーを動かします。

## スクリーンリーダー

- 画像は画像のロールを持ち、`alt` が名前になります。
- ツールバーと編集バーには、「画像の操作」「編集の操作」のように独自の名前があります。
- フォーカスだけではわからない変化はすべて読み上げで知らせます。ズームの倍率、編集モードの開始、動かした角の位置、スライダーの値、適用の結果です。

## タッチスクリーン

- `pointer: coarse` では、ボタンと角のハンドルが 44 ピクセル以上になります。
- 指で角をドラッグしている間、ルーペが指の下の領域を表示します。
- 画像がフィットしている間は 1 本指でページがスクロールするため、ビューアーの中に閉じ込められることはありません。ズームすると画像が移動します。

## 設定

- **動きを減らす。** `prefers-reduced-motion: reduce` では、ボタンの状態がトランジションなしで切り替わります。
- **強制カラー。** Windows のハイコントラストなどの強制カラーモードでも、押されたボタンと主要な操作には見える輪郭が残ります。
- **ダークモード。** 色は `prefers-color-scheme` に従います。[スタイル](./styling#dark-mode)を参照してください。
