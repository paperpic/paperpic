# プレイグラウンド

サンプルのレシートで PaperPic を試すか、自分の画像を添付できます。画像はブラウザーの外に送信されません。拡大と移動ができます。編集するには、鉛筆を押して画像を切り抜き、傾き補正、回転のいずれかを行い、変更を適用すると結果をダウンロードできます。
