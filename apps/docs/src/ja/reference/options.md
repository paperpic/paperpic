# オプション

オプションは、ビューアーに何を表示し、ユーザーが何をできるかを決めます。ビューアーの作成時に渡すか、あとから [`setOptions()`](./methods#setoptions) で変更します。Vue と React のコンポーネントは、同じ名前の props として受け取ります。

```ts
const pic = new PaperPic(container, { src: '/receipt.jpg', alt: 'レシート' })

pic.setOptions({ editable: false })
```

`setOptions()` は渡したオプションだけを変更し、`undefined` を渡すとそのオプションはデフォルト値に戻ります。`change` は発生しません。

## 画像

### `src`

- **型:** `string | Blob`
- **デフォルト:** なし

表示する画像です。同一オリジンの URL か、クライアントで添付された `File` または `Blob` を指定します。

同じ値をもう一度渡しても画像は再読み込みされないため、編集の結果は表示されたままです。元画像に戻すには [`reload()`](./methods#reload) を呼び出します。編集中に新しい値を渡すと、変更は破棄されます。

### `alt`

- **型:** `string`
- **デフォルト:** `''`

スクリーンリーダー向けの画像の説明です。`alt` がない場合、スクリーンリーダーは `alt` が空の `<img>` と同じく画像を読み飛ばします。

## インターフェース

### `editable`

- **型:** `boolean`
- **デフォルト:** `true`

ユーザーが画像を編集できるかどうかです。`false` にすると読み取り専用のビューアーになり、ツールバーに画像を回転するボタンが加わります。この回転は表示だけを変えます。編集中にこのオプションを変更すると、変更は破棄されます。

### `toolbar`

- **型:** `boolean`
- **デフォルト:** `true`

組み込みのツールバーと編集バーを表示するかどうかです。表示しない場合は、[メソッド](./methods)を使って独自の操作を作ります。

### `tools`

- **型:** `readonly ToolId[]`
- **デフォルト:** すべてのツール

編集バーに表示するツールです。配列の順序にかかわらず、この表の順に並びます。

| Id              | ボタン                       |
| --------------- | ---------------------------- |
| `'crop'`        | 切り抜き                     |
| `'perspective'` | 傾き補正                     |
| `'rotate'`      | 左に回転                     |
| `'flip'`        | 反転                         |
| `'adjust'`      | 調整（明るさとコントラスト） |
| `'threshold'`   | クリーンアップ               |

### `wheelZoom`

- **型:** `boolean`
- **デフォルト:** `true`

ホイールで画像をズームするかどうかです。長いページの中にビューアーを置く場合はオフにすると、ホイールでページがスクロールします。

### `download`

- **型:** `boolean`
- **デフォルト:** `false`

表示中の画像を保存するボタンをツールバーに置くかどうかです。保存されるのは最後の適用の結果、なければ元画像です。編集中はボタンが隠れます。[`download`](./events#download) イベントを使えば、別の方法でファイルを保存できます。

### `labels`

- **型:** `Partial<PaperPicLabels>`
- **デフォルト:** 英語のテキスト

コンポーネントが表示または読み上げるテキストを置き換えます。すべてのキーは[ラベル](./labels)にあります。

### `icons`

- **型:** `Partial<PaperPicIcons>`
- **デフォルト:** 組み込みのアイコン

任意のアイコンを、`<svg>` などの 1 つの要素からなる独自のマークアップに置き換えます。マークアップは HTML としてページに入るため、信頼できるマークアップだけを渡してください。空文字列を渡すと、そのアイコンのボタンはアイコンなしになります。例は[スタイル](../guide/styling#icons)にあります。

各キーはアイコンを表し、2 つのボタンに出るアイコンもあります。

| キー             | ボタン                                             |
| ---------------- | -------------------------------------------------- |
| `adjust`         | 調整                                               |
| `apply`          | 適用、および各ツールの完了                         |
| `brightness`     | 「調整」のパネルの明るさ                           |
| `cancel`         | キャンセル、およびこのツールをキャンセル           |
| `contrast`       | 「調整」のパネルのコントラスト                     |
| `crop`           | 切り抜き                                           |
| `download`       | ダウンロード                                       |
| `edit`           | 編集                                               |
| `fitHeight`      | 高さに合わせる                                     |
| `fitWidth`       | 幅に合わせる                                       |
| `flip`           | 反転                                               |
| `perspective`    | 傾き補正                                           |
| `redo`           | やり直す                                           |
| `rotateDocument` | 編集バーの左に回転                                 |
| `rotateLeft`     | 読み取り専用のビューアーのツールバーにある左に回転 |
| `rotateRight`    | 読み取り専用のビューアーのツールバーにある右に回転 |
| `threshold`      | クリーンアップ                                     |
| `undo`           | 元に戻す                                           |
| `zoomIn`         | 拡大                                               |
| `zoomOut`        | 縮小                                               |

## 結果

### `output`

- **型:** `{ type?: string, quality?: number }`
- **デフォルト:** 元画像の形式

編集後の画像の形式です。`type` は `'image/jpeg'`、`'image/png'`、`'image/webp'` のいずれかで、`quality` は JPEG と WebP で 0 から 1、デフォルトは `0.92` です。

`type` がない場合、クリーンアップした画像は PNG になります。JPEG だとくっきりした輪郭が崩れるためです。それ以外の画像は元画像の形式を保ちます。ブラウザーがエンコードできない形式は PNG になります。

### `maxOutputSize`

- **型:** `number`
- **デフォルト:** フル解像度

編集後の画像の長辺のピクセル数です。これより大きい結果は縮小されます。

### `filename`

- **型:** `string`
- **デフォルト:** 元画像の名前

保存するファイルの名前です。拡張子は画像の形式に合わせるため、クリーンアップした `receipt.jpg` は `receipt.png` として保存されます。`Blob` のように元画像に名前がない場合、ファイル名は `image` になります。

## ツール

### `aspectRatio`

- **型:** `number`
- **デフォルト:** 推定

文書の実際の縦横比で、幅を高さで割った値です。たとえば A4 用紙なら `210 / 297` です。傾き補正は結果をこの縦横比にします。指定しない場合は写真から推定します。

### `softness`

- **型:** `number`（0 から 1）
- **デフォルト:** `0.25`

クリーンアップが文字の輪郭に残すグレーの量です。グレーが残ると文字が読みやすくなります。`0` にすると厳密な白黒になり、ファイルは小さくなりますが細い線が途切れます。
