# 옵션

옵션은 뷰어가 무엇을 보여 주고 사용자가 무엇을 할 수 있는지 정합니다. 뷰어를 만들 때 전달하거나, 나중에 [`setOptions()`](./methods#setoptions)로 바꿉니다. Vue와 React 컴포넌트는 같은 이름의 props로 받습니다.

```ts
const pic = new PaperPic(container, { src: '/receipt.jpg', alt: '영수증' })

pic.setOptions({ editable: false })
```

`setOptions()`는 전달한 옵션만 바꾸고, `undefined`를 전달하면 해당 옵션이 기본값으로 돌아갑니다. `change`는 발생하지 않습니다.

## 이미지

### `src`

- **타입:** `string | Blob`
- **기본값:** 없음

보여 줄 이미지입니다. 같은 출처의 URL이나, 클라이언트에서 첨부한 `File` 또는 `Blob`을 지정합니다.

같은 값을 다시 전달해도 이미지를 다시 불러오지 않으므로, 편집 결과가 화면에 그대로 남습니다. 원본 이미지로 돌아가려면 [`reload()`](./methods#reload)를 호출하세요. 편집 중에 새 값을 전달하면 변경 사항이 취소됩니다.

### `alt`

- **타입:** `string`
- **기본값:** `''`

스크린 리더를 위한 이미지 설명입니다. `alt`가 없으면 스크린 리더는 `alt`가 비어 있는 `<img>`처럼 이미지를 건너뜁니다.

## 인터페이스

### `editable`

- **타입:** `boolean`
- **기본값:** `true`

사용자가 이미지를 편집할 수 있는지 여부입니다. `false`이면 읽기 전용 뷰어가 되고, 도구 모음에 이미지를 회전하는 버튼이 추가됩니다. 이 회전은 표시만 바꿉니다. 편집 중에 이 옵션을 바꾸면 변경 사항이 취소됩니다.

### `toolbar`

- **타입:** `boolean`
- **기본값:** `true`

기본 제공 도구 모음과 편집 바를 표시할지 여부입니다. 표시하지 않으면 [메서드](./methods)로 직접 컨트롤을 만드세요.

### `tools`

- **타입:** `readonly ToolId[]`
- **기본값:** 모든 도구

편집 바에 표시할 도구입니다. 배열의 순서와 관계없이 이 표의 순서대로 나옵니다.

| Id              | 버튼               |
| --------------- | ------------------ |
| `'crop'`        | 자르기             |
| `'perspective'` | 기울기 보정        |
| `'rotate'`      | 왼쪽으로 회전      |
| `'flip'`        | 뒤집기             |
| `'adjust'`      | 조정 (밝기와 대비) |
| `'threshold'`   | 정리               |

### `wheelZoom`

- **타입:** `boolean`
- **기본값:** `true`

휠로 이미지를 확대/축소할지 여부입니다. 긴 페이지 안에 뷰어가 있을 때 끄면, 휠이 페이지를 스크롤합니다.

### `download`

- **타입:** `boolean`
- **기본값:** `false`

화면에 보이는 이미지를 저장하는 버튼을 도구 모음에 둘지 여부입니다. 저장되는 것은 마지막 적용의 결과이고, 없으면 원본 이미지입니다. 편집 중에는 버튼이 숨겨집니다. [`download`](./events#download) 이벤트로 파일을 다른 방법으로 저장할 수 있습니다.

### `labels`

- **타입:** `Partial<PaperPicLabels>`
- **기본값:** 영어 텍스트

컴포넌트가 표시하거나 읽어 주는 텍스트를 바꿉니다. 모든 키는 [레이블](./labels)에 있습니다.

### `icons`

- **타입:** `Partial<PaperPicIcons>`
- **기본값:** 내장 아이콘

어떤 아이콘이든 `<svg>` 같은 요소 하나로 된 직접 만든 마크업으로 바꿉니다. 마크업은 HTML로 페이지에 들어가므로, 신뢰할 수 있는 마크업만 전달하세요. 빈 문자열을 주면 그 아이콘의 버튼은 아이콘 없이 표시됩니다. 예시는 [스타일](../guide/styling#icons)에 있습니다.

각 키는 아이콘 하나를 가리키며, 두 버튼에 나오는 아이콘도 있습니다.

| 키               | 버튼                                              |
| ---------------- | ------------------------------------------------- |
| `adjust`         | 조정                                              |
| `apply`          | 적용, 그리고 자르기와 기울기 보정의 완료          |
| `cancel`         | 취소, 그리고 이 도구 취소                         |
| `crop`           | 자르기                                            |
| `download`       | 다운로드                                          |
| `edit`           | 편집                                              |
| `fitHeight`      | 높이에 맞추기                                     |
| `fitWidth`       | 너비에 맞추기                                     |
| `flip`           | 뒤집기                                            |
| `perspective`    | 기울기 보정                                       |
| `redo`           | 다시 실행                                         |
| `rotateDocument` | 편집 바의 왼쪽으로 회전                           |
| `rotateLeft`     | 읽기 전용 뷰어의 도구 모음에 있는 왼쪽으로 회전   |
| `rotateRight`    | 읽기 전용 뷰어의 도구 모음에 있는 오른쪽으로 회전 |
| `threshold`      | 정리                                              |
| `undo`           | 실행 취소                                         |
| `zoomIn`         | 확대                                              |
| `zoomOut`        | 축소                                              |

## 결과

### `output`

- **타입:** `{ type?: string, quality?: number }`
- **기본값:** 원본 이미지의 형식

편집한 이미지의 형식입니다. `type`은 `'image/jpeg'`, `'image/png'`, `'image/webp'` 중 하나이고, `quality`는 JPEG와 WebP에서 0부터 1까지이며 기본값은 `0.92`입니다.

`type`이 없으면 정리한 이미지는 PNG가 됩니다. JPEG는 선명한 가장자리를 망가뜨리기 때문입니다. 그 밖의 이미지는 원본의 형식을 유지합니다. 브라우저가 인코딩할 수 없는 형식은 PNG가 됩니다.

### `maxOutputSize`

- **타입:** `number`
- **기본값:** 원본 해상도

편집한 이미지의 긴 변의 길이(픽셀)입니다. 이보다 큰 결과는 축소됩니다.

### `filename`

- **타입:** `string`
- **기본값:** 원본 이미지의 이름

저장되는 파일의 이름입니다. 확장자는 이미지 형식을 따르므로, 정리한 `receipt.jpg`는 `receipt.png`로 저장됩니다. `Blob`처럼 원본에 이름이 없으면 파일 이름은 `image`입니다.

## 도구

### `aspectRatio`

- **타입:** `number`
- **기본값:** 추정

문서의 실제 가로세로 비율로, 너비를 높이로 나눈 값입니다. 예를 들어 A4 용지는 `210 / 297`입니다. 기울기 보정은 결과를 이 비율로 만듭니다. 지정하지 않으면 사진에서 비율을 추정합니다.

### `softness`

- **타입:** `number`, 0부터 1까지
- **기본값:** `0.25`

정리가 글자 가장자리에 남기는 회색의 양입니다. 회색이 남으면 글자를 읽기 쉬워집니다. `0`은 엄격한 흑백으로, 파일은 작아지지만 가는 획이 끊깁니다.
