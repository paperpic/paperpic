# 뷰어

작은 글씨와 긴 영수증은 화면에서 한눈에 읽기 어렵습니다. 뷰어는 이미지를 불러올 때 맞추고, 어느 부분이든 확대해서 볼 수 있게 합니다.

<Demo src="/samples/receipt.jpg" alt="영수증" :editable="false" />

## 확대/축소와 이동

| 동작                    | 마우스와 트랙패드          | 터치    | 키보드    |
| ----------------------- | -------------------------- | ------- | --------- |
| 확대/축소               | 휠, 또는 트랙패드에서 핀치 | 핀치    | `+`와 `-` |
| 이동                    | 드래그                     | 드래그  | 화살표 키 |
| 맞추기와 100% 사이 전환 | 더블 클릭                  | 더블 탭 |           |
| 이미지 전체 맞추기      |                            |         | `0`       |

키보드는 뷰어에 포커스가 있을 때 동작합니다. 핀치는 두 손가락 사이의 점을 기준으로 확대/축소합니다.

배율은 이미지 전체를 맞춘 배율(작은 이미지는 100%)부터 800%까지입니다. 들어맞는 이미지는 가운데에 머물고, 넘치는 이미지는 가장자리까지 이동할 수 있습니다.

이미지를 불러오면 뷰어에 전체가 맞춰지고, 사용자가 직접 확대/축소하기 전까지는 뷰어 크기가 바뀌어도 맞춤이 유지됩니다.

긴 페이지에서는 휠이 페이지를 스크롤하는 대신 이미지를 확대/축소하게 됩니다. 그런 곳에서는 `wheelZoom: false`로 설정하세요. 버튼, 키보드, 터치스크린의 핀치로는 계속 확대/축소할 수 있습니다.

## 도구 모음

도구 모음은 뷰어 오른쪽에 있으며, 뷰어가 버튼을 모두 담기에 너무 낮으면 스크롤됩니다.

| 버튼                               | 하는 일                                                                 |
| ---------------------------------- | ----------------------------------------------------------------------- |
| ‘편집’                             | [편집 모드](./editing)를 시작합니다. `editable: false`에서는 숨겨집니다 |
| ‘확대’, ‘축소’                     | 중앙을 기준으로 한 단계 확대/축소합니다                                 |
| ‘너비에 맞추기’, ‘높이에 맞추기’   | 너비(긴 문서에 알맞음) 또는 높이를 맞춥니다                             |
| ‘왼쪽으로 회전’, ‘오른쪽으로 회전’ | 읽기 전용 뷰어에서만: 화면의 이미지를 회전합니다                        |
| ‘다운로드’                         | `download: true`일 때만: 화면의 이미지를 저장합니다                     |

`toolbar: false`이면 도구 모음과 편집 바가 숨겨지고, [메서드](../reference/methods)로 직접 컨트롤을 만들 수 있습니다.

## 읽기 전용 뷰어

`editable: false`이면 ‘편집’ 버튼이 사라지고, 도구 모음에 이미지를 회전하는 버튼 두 개가 생깁니다. 이 회전은 표시만 바꾸며 아무것도 저장하지 않습니다. 기록의 첨부 파일처럼 읽어야 하지만 바뀌면 안 되는 문서에 쓰세요.

:::tabs key:framework
== JavaScript

```ts
const pic = new PaperPic(container, {
  src: '/receipt.jpg',
  alt: '영수증',
  editable: false,
})
```

== Vue

```vue
<PaperPic src="/receipt.jpg" alt="영수증" :editable="false" />
```

== React

```tsx
<PaperPic src="/receipt.jpg" alt="영수증" editable={false} />
```

:::

## 코드로 보기 제어하기

[`zoomIn()`](../reference/methods#zoomin), [`zoomOut()`](../reference/methods#zoomout), [`zoomTo()`](../reference/methods#zoomto), [`fit()`](../reference/methods#fit) 메서드는 버튼과 같은 일을 하고, [`getState()`](../reference/methods#getstate)는 현재 배율과 맞추기 방식을 알려 줍니다.

```ts
pic.fit('width')
pic.zoomTo(2)

const { zoom, fit } = pic.getState()
```
