# PaperPic이란?

문서 사진은 기울어 있거나, 그림자가 지거나, 배경이 많이 찍혀서 들어옵니다. PaperPic은 이런 사진을 확대할 수 있는 뷰어로 보여 주고, 스캐너 앱처럼 앱이 저장하기 전에 사진마다 기울기를 보정하고 정리할 수 있게 합니다.

## 할 수 있는 일

- **보기.** 버튼, 휠, 핀치로 확대/축소하고, 이미지를 이동하고, 이미지 전체나 너비, 높이에 맞춥니다. 읽기 전용 뷰어는 이미지를 회전할 수도 있습니다.
- **편집.** 편집 모드에서 사용자는 자르기, 비스듬히 찍은 사진의 기울기 보정, 회전, 뒤집기, 밝기와 대비 조정, 문서를 흑백으로 정리할 수 있습니다. 사용자가 변경을 적용하기 전까지 모든 변경은 실행 취소할 수 있습니다.
- **전달.** 적용하면 결과를 원본 해상도로 계산해 `Blob`으로 코드에 넘깁니다. 다운로드 버튼으로 저장할 수도 있습니다.

모든 단계는 사용자가 요청할 때만 일어납니다. 사진이 저절로 바뀌는 일은 없습니다.

## 하지 않는 일

- 아무것도 업로드하지 않습니다. 결과를 어떻게 할지는 앱이 정합니다.
- PDF 파일은 열지 않고, 이미지만 엽니다.
- 문서의 가장자리를 스스로 찾지 않습니다. 사용자가 모서리를 끌어 옮깁니다.

## 패키지

| 패키지            | 사용 환경                            |
| ----------------- | ------------------------------------ |
| `@paperpic/core`  | 순수 JavaScript 또는 모든 프레임워크 |
| `@paperpic/vue`   | Vue 3.5 이상                         |
| `@paperpic/react` | React 19 이상                        |

세 패키지는 옵션, 이벤트, 메서드가 같고, 코어에는 런타임 의존성이 없습니다. 편집은 Web Worker에서 실행되므로 큰 사진에서도 페이지가 계속 반응합니다.

## 사용해 보기

[플레이그라운드](../playground)에서 예시 영수증이나, 브라우저 밖으로 나가지 않는 내 사진을 편집해 볼 수 있습니다. 앱에 PaperPic을 추가하려면 [시작하기](./getting-started)로 가세요.
