# 자르기

문서 사진에는 책상이나 손, 주변의 다른 종이가 함께 찍히곤 합니다. ‘자르기’는 문서가 담긴 직사각형만 남기고 나머지는 버립니다.

## 사용 방법

1. ‘편집’을 누른 다음 ‘자르기’를 누릅니다. 이미지 안에 모서리마다 핸들이 달린 직사각형이 나타납니다.
2. 직사각형이 문서를 감쌀 때까지 모서리를 끌어 옮깁니다. 확대/축소 버튼을 계속 쓸 수 있으므로, 확대해서 정확하게 놓을 수 있습니다.
3. ‘완료’ 또는 `Enter`를 누르면 자르기가 변경에 더해집니다. ‘이 도구 취소’ 또는 `Esc`는 아무것도 바꾸지 않고 ‘자르기’를 닫습니다.

자르기는 다른 변경과 같습니다. ‘실행 취소’로 없앨 수 있고, ‘적용’으로 확정됩니다.

## 모서리 핸들

- 핸들은 이미지 안에 머물고, 직사각형은 뒤집히지 않습니다.
- 터치스크린에서는 모서리를 끄는 동안 돋보기가 손가락 아래 영역을 보여 주므로, 손가락이 모서리 위치를 가리지 않습니다.
- 끌지 않고도 핸들을 누른 다음 모서리가 갈 위치를 탭하면 됩니다. 그때까지 핸들은 강조 표시되고, `Esc`로 선택을 해제합니다.
- 키보드에서는 Tab으로 핸들을 오가고, 화살표 키로 포커스가 있는 핸들을 화면 1픽셀씩, Shift와 함께 누르면 10픽셀씩 옮깁니다. 스크린 리더가 이동할 때마다 읽어 줍니다.

## ‘자르기’와 ‘기울기 보정’ 중 무엇을 쓸까요?

‘자르기’는 직사각형을 그대로 남깁니다. 비스듬히 찍은 사진에서는 문서가 사다리꼴로 보여 직사각형이 맞지 않습니다. 그런 사진에는 [‘기울기 보정’](./straighten)을 쓰세요. 모서리를 하나씩 옮겨 페이지를 평평하게 만듭니다.

## 코드에서 쓰기

‘자르기’는 기본적으로 편집 바에 있으며, [`tools`](../../reference/options#tools)에서의 id는 `'crop'`입니다. `toolbar: false`일 때는 [`openTool()`](../../reference/methods#opentool)으로 열고 [`confirmTool()`](../../reference/methods#confirmtool)이나 [`cancelTool()`](../../reference/methods#canceltool)로 닫습니다.

```ts
pic.edit()
pic.openTool('crop')

// 나중에, 직접 만든 버튼에서
pic.confirmTool()
```
