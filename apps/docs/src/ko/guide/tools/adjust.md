# 조정

어두운 곳에서 찍은 사진은 어둡거나 칙칙하게 나옵니다. ‘조정’은 색을 유지하면서 밝기와 대비를 바꿉니다. 컬러 서식이나 사진처럼 흑백이 되면 안 되는 문서에 씁니다.

## 사용 방법

1. ‘편집’을 누른 다음 ‘조정’을 누릅니다. 도구 대신 패널이 열리고, 눈금자와 함께 눈금자가 바꿀 색조를 고르는 ‘밝기’와 ‘대비’가 나타납니다.
2. 눈금자를 끌어 옮깁니다. 끄는 동안 미리보기가 바뀝니다. ‘대비’를 고르면 같은 눈금자로 다른 색조를 바꿉니다.
3. ‘완료’를 누르면 두 색조가 변경 하나로 남으며 ‘실행 취소’로 없앨 수 있습니다. ‘이 도구 취소’는 이미지를 그대로 둡니다.

눈금자의 가운데는 이미지를 그대로 두며, 바늘이 가운데에 걸리므로 변경 없는 상태로 쉽게 돌아갈 수 있습니다. 스크린 리더는 ‘밝기 +30’처럼 -100부터 100까지의 값을 읽어 줍니다. ‘조정’과 패널 안의 각 색조에 붙는 점은 값이 0이 아님을 나타냅니다.

‘조정’은 다른 변경 다음에 적용되므로, ‘자르기’와 ‘기울기 보정’에서는 조정된 이미지가 보입니다.

## ‘조정’과 ‘정리’ 중 무엇을 쓸까요?

| ‘조정’                       | [‘정리’](./clean-up) |
| ---------------------------- | -------------------- |
| 색과 회색을 유지             | 문서를 흑백으로 만듦 |
| 컬러 서식, 도장, 사진에 적합 | 종이 위 글자에 적합  |
| 원본 이미지 형식 유지        | PNG가 됨             |

‘정리’가 켜져 있는 동안에는 ‘조정’을 쓸 수 없습니다. 정리한 문서에는 고유한 색조가 있기 때문입니다.

## 코드에서 쓰기

[`setAdjustments()`](../../reference/methods#setadjustments)는 -1부터 1까지의 값을 받고 0은 변화 없음입니다. [`getState()`](../../reference/methods#getstate)는 값을 `adjustments`로 반환합니다.

```ts
pic.edit()
pic.setAdjustments({ brightness: 0.2, contrast: 0.3 })
```

‘조정’이 열려 있는 동안 `setAdjustments()`는 패널에 보이는 값을 바꾸고, [`confirmTool()`](../../reference/methods#confirmtool)은 이를 변경 하나로 남깁니다.

[`tools`](../../reference/options#tools) 옵션에서 ‘조정’은 `'adjust'`입니다.
