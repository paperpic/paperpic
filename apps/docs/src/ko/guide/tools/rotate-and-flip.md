# 회전과 뒤집기

휴대폰은 문서 사진을 옆으로 눕히거나 거꾸로 저장하곤 하고, 어떤 스캔은 좌우가 뒤바뀌어 나옵니다. ‘왼쪽으로 회전’과 ‘뒤집기’는 방향을 바로잡고 이미지의 나머지는 그대로 둡니다.

## 회전

편집 바의 ‘왼쪽으로 회전’은 사진 갤러리처럼 이미지를 시계 반대 방향으로 90도 회전합니다. 두 번 누르면 180도, 세 번 누르면 시계 방향으로 90도가 됩니다.

회전은 변경입니다. ‘실행 취소’로 없앨 수 있고, ‘적용’으로 확정됩니다. 네 번 회전하면 원래 방향으로 돌아오고, 그러면 적용할 것이 없습니다.

코드에서는 [`rotate()`](../../reference/methods#rotate)에 `1`을 주면 시계 방향, `-1`을 주면 시계 반대 방향으로 회전합니다.

```ts
pic.rotate(1)
pic.rotate(-1)
```

## 뒤집기

‘뒤집기’는 보이는 그대로 이미지를 좌우로 뒤집습니다. 90도 회전한 뒤에도 화면에서 좌우로 뒤집습니다. 이미지를 위아래로 바꾸려면 뒤집은 다음 두 번 회전하세요.

서로 상쇄되는 뒤집기와 회전은 적용할 것을 남기지 않습니다. 코드에서는 [`flip()`](../../reference/methods#flip)을 호출합니다.

## 읽기 전용 뷰어에서

[`editable: false`](../viewer#read-only)에서는 도구 모음에 ‘왼쪽으로 회전’과 ‘오른쪽으로 회전’ 버튼이 있습니다. 화면의 이미지만 돌리며, 아무것도 저장되지 않고 `apply` 이벤트도 발생하지 않습니다. [`rotate()`](../../reference/methods#rotate)는 코드에서 같은 일을 합니다. 읽기 전용 뷰어에는 ‘뒤집기’가 없습니다.

## Id

[`tools`](../../reference/options#tools) 옵션에서 ‘왼쪽으로 회전’은 `'rotate'`, ‘뒤집기’는 `'flip'`입니다.
