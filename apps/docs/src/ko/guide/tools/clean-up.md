# 정리

종이 위의 글자는 흑백일 때 가장 잘 읽히지만, 사진에는 그림자, 고르지 않은 빛, 회색빛 종이가 담깁니다. ‘정리’는 각 픽셀을 주변과 비교해 잉크인지 종이인지 판단하므로, 그림자와 고르지 않은 빛은 사라지고 글자는 선명하게 남습니다. API에서의 id는 `threshold`입니다.

## 사용 방법

1. ‘편집’을 누른 다음 ‘정리’를 누릅니다. 미리보기가 흑백으로 바뀌고 ‘민감도’ 슬라이더가 나타납니다.
2. 슬라이더를 끌어 옮깁니다. 민감도를 높이면 더 많은 픽셀이 어두워져 흐리거나 닳은 글자를 살려 냅니다. 민감도를 낮추면 뒷면에서 비치는 글자 없이 더 깨끗한 페이지가 됩니다. 슬라이더를 놓으면 변경이 하나 남습니다.
3. ‘정리’를 다시 누르면 꺼집니다.

‘정리’는 항상 다른 변경 다음에 적용됩니다. ‘자르기’와 ‘기울기 보정’은 정리하지 않은 이미지를 보여 줍니다. 정리한 페이지에서는 종이 가장자리를 찾기 어렵기 때문입니다.

## 부드러움

[`softness`](../../reference/options#softness)는 ‘정리’가 글자 가장자리에 남기는 회색의 양을 0부터 1까지로 정하며, 기본값은 0.25입니다. 회색이 조금 남으면 가장자리가 매끄러워지고 작은 글씨를 읽기 쉬워집니다. `0`은 엄격한 흑백으로, 파일은 작아지지만 가는 획이 끊깁니다.

## 결과 형식

정리한 이미지는 PNG가 됩니다. JPEG는 선명한 가장자리 주변에 잡티를 만들기 때문입니다. [`output`](../../reference/options#output) 옵션으로 다른 형식을 고를 수 있습니다.

## 코드에서 쓰기

[`setThreshold()`](../../reference/methods#setthreshold)는 ‘정리’를 켜거나 끄고, 민감도를 0부터 1까지로 정합니다. 기본값은 0.5입니다. [`getState()`](../../reference/methods#getstate)는 둘 다 `threshold`로 반환합니다.

```ts
pic.edit()
pic.setThreshold({ enabled: true, sensitivity: 0.6 })
```
