# 가리기

문서 사진에는 계좌 번호, 서명, 배경의 얼굴처럼 보여서는 안 될 것이 찍히기도 합니다. ‘가리기’는 반듯하거나 기울어진 직사각형을 단색 검정이나 흰색으로 덮고, 결과에는 그 아래에 있던 내용이 남지 않습니다.

## 사용 방법

1. ‘편집’을 누른 다음 ‘가리기’를 누릅니다. 이미지 가운데에 모서리마다 핸들이 달린 띠가 나타납니다.
2. 가릴 부분 위에 영역을 그리세요. 이미지 어디서든, 띠 위에서도, 영역의 한 모서리에서 반대쪽 모서리까지 끕니다. 그런 다음 영역을 끌면 옮길 수 있고, 위쪽 핸들로 회전하면 기울어진 글줄에 맞출 수 있고, 모서리를 끌면 크기가 바뀝니다. 영역은 반투명하게 색을 보여 주므로 정확한 글자 위에 놓을 수 있습니다.
3. 패널에서 ‘검정’이나 ‘흰색’을 고릅니다.
4. ‘완료’나 `Enter`를 누르면 영역이 변경에 더해집니다. ‘이 도구 취소’나 `Esc`는 아무것도 바꾸지 않고 ‘가리기’를 닫습니다.

영역을 배치하기 전까지만 그릴 수 있습니다. 영역을 그리거나 옮기거나 회전하거나 크기를 바꾸면, 이미지의 나머지 부분을 끌 때 다시 이미지가 이동하므로 영역이 실수로 바뀌지 않습니다. 그 전에는 확대한 이미지를 두 손가락으로, 또는 이미지에 포커스가 있을 때 화살표 키로 이동합니다. 끌지 않으면 띠가 영역이 됩니다. 키보드로 옮기거나, 띠를 누른 뒤 옮길 곳을 탭하세요.

‘완료’를 누를 때마다 영역이 하나씩 추가되므로, 다른 부분을 가리려면 ‘가리기’를 다시 엽니다. ‘실행 취소’는 마지막 영역을 없애고, 색은 다음 영역에도 그대로 쓰입니다. 모서리 핸들은 ‘[자르기](./crop)’와 같이 끌거나, 핸들을 누른 뒤 옮길 곳을 탭하거나, 키보드로 움직입니다. 영역 위의 핸들에서는 화살표 키로 1도, Shift를 누르면 10도 회전합니다. 끌 때는 수평에 맞춰집니다.

## 보장하는 것 {#guarantees}

- 영역은 다른 모든 변경 뒤에 덮이므로, ‘조정’과 ‘정리’가 검정이나 흰색을 흐리게 만들지 않습니다.
- 영역은 이후의 변경을 따라갑니다. 회전, 뒤집기, 자르기는 이미지와 함께 영역을 옮기고, ‘기울기 보정’은 페이지와 함께 영역을 변형합니다.
- 가장자리가 조금이라도 닿는 픽셀은 모두 덮으며, 투명한 PNG에서도 불투명합니다.
- ‘적용’은 결과에 단색 픽셀을 기록하므로, 파일에는 덮인 내용이 전혀 남지 않습니다.

‘적용’ 전까지는 뷰어가 원본을 가지고 있으므로 ‘실행 취소’로 영역 아래의 내용을 되돌릴 수 있습니다. 공유할 때는 원본이 아니라 ‘적용’의 결과를 공유하세요.

## 코드에서 쓰기

‘가리기’는 기본으로 편집 바에 있으며, [`tools`](../../reference/options#tools)에서 id는 `'redact'`입니다. `toolbar: false`일 때는 [`openTool()`](../../reference/methods#opentool)로 열고, [`setRedaction()`](../../reference/methods#setredaction)으로 색을 고르고, [`confirmTool()`](../../reference/methods#confirmtool)이나 [`cancelTool()`](../../reference/methods#canceltool)로 닫습니다.

```ts
pic.edit()
pic.openTool('redact')
pic.setRedaction({ color: 'white' })

// 나중에, 직접 만든 버튼에서
pic.confirmTool()
```

[상태](../../reference/state)의 `redaction`에 사용 중인 색이 있습니다.
