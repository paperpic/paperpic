# 기울기 보정

비스듬히 찍은 문서는 사다리꼴로 보입니다. 먼 쪽 가장자리가 짧아지고 글자가 기울어집니다. ‘기울기 보정’은 스캔한 것처럼 평평한 직사각형 페이지로 되돌립니다. API에서의 id는 `perspective`입니다.

<Demo src="/samples/receipt.jpg" alt="영수증" :tools="['perspective']" />

## 사용 방법

1. ‘편집’을 누른 다음 ‘기울기 보정’을 누릅니다. 모서리마다 핸들이 나타나며, 뷰어가 문서를 [찾으면](#finding-the-document) 문서 위에 놓입니다.
2. 어긋난 핸들을 문서의 모서리로 끌어 옮깁니다. 패널의 확대/축소 버튼으로 확대하면 정확하게 놓을 수 있습니다.
3. 용지를 알고 있다면 [크기](#paper-size)를 ‘A4’, ‘레터’, ‘카드’ 중에서 고릅니다. ‘자동’은 추정합니다.
4. ‘완료’ 또는 `Enter`를 누릅니다. 뷰어가 네 모서리에 맞춰 잘린 평평한 페이지를 보여 줍니다. ‘완료’는 뷰어가 문서를 찾거나 모서리를 움직일 때까지 기다립니다.

핸들은 [‘자르기’](./crop)와 같이 동작합니다. 터치스크린에서는 돋보기가 나오고, 끄는 대신 눌렀다가 탭할 수도 있으며, 키보드에서는 Tab과 화살표 키를 씁니다. 네 모서리는 항상 볼록한 모양을 유지하므로, 페이지를 언제든 평평하게 만들 수 있습니다.

‘기울기 보정’은 [‘정리’](./clean-up)의 흑백 없이 사진을 보여 줍니다. 정리된 페이지에서는 종이 가장자리를 찾기 어렵기 때문입니다. 흑백은 ‘완료’ 뒤에 돌아오고, 회색은 그대로 남습니다.

## 문서 찾기 {#finding-the-document}

‘기울기 보정’을 열면 뷰어가 사진에서 문서를 찾아 네 모서리를 그 위에 놓으므로, ‘완료’를 바로 누를 수 있습니다. 찾는 작업은 브라우저 안에서 순식간에 끝나며, ‘완료’ 전까지 아무것도 바꾸지 않습니다.

뷰어는 충분히 확실한 것만 제안합니다. 종이가 책상과 잘 구분되지 않거나 사진에 문서가 없으면, 모서리는 이미지 안쪽에서 시작해 사용자를 기다립니다. 사용자가 이미 건드린 모서리는 절대 저절로 움직이지 않습니다.

## 용지 크기 {#paper-size}

‘기울기 보정’ 패널에는 용지 크기가 있어, 결과를 그 용지의 정확한 비율로 만듭니다.

| 선택 | 비율                                                                              |
| ---- | --------------------------------------------------------------------------------- |
| 자동 | [`aspectRatio`](../../reference/options#aspectratio), 없으면 [추정](#proportions) |
| A4   | 210 × 297 mm, A3와 A5도 같습니다                                                  |
| 레터 | 8.5 × 11인치, US 레터                                                             |
| 카드 | 85.6 × 53.98 mm, 신분증이나 은행 카드                                             |

크기는 비율만 정합니다. 모서리를 옮기지는 않습니다. 세로인지 가로인지는 모서리를 따르므로 방향을 고를 필요가 없습니다. 문서와 다른 크기는 문서를 일그러뜨리므로, ‘기울기 보정’은 열 때마다 ‘자동’으로 시작합니다.

네 모서리가 이미지의 모서리에 있으면 ‘자동’은 아무것도 바꾸지 않고, 크기를 고르면 이미지 전체가 그 용지의 비율이 됩니다.

## 비율 {#proportions}

사진만으로는 페이지의 실제 모양을 알 수 없으므로, ‘기울기 보정’은 사진 속 모서리 위치로 비율을 추정합니다. 보통 거리에서 찍은 사진에는 잘 맞지만, 정확할 수는 없습니다.

추정에는 원래 사진이 쓰입니다. 같은 편집에서 자르거나 회전한 뒤에도 마찬가지입니다. 사용자가 적용하면 그 결과가 새 사진으로 취급되므로, 기울기 보정은 적용하기 전에 하세요.

문서를 알고 있다면 [`aspectRatio`](../../reference/options#aspectratio)에 너비를 높이로 나눈 값을 지정하세요. 결과가 그 비율을 따릅니다.

:::tabs key:framework
== JavaScript

```ts
const pic = new PaperPic(container, {
  src: '/invoice.jpg',
  aspectRatio: 210 / 297,
})
```

== Vue

```vue
<PaperPic src="/invoice.jpg" :aspect-ratio="210 / 297" />
```

== React

```tsx
<PaperPic src="/invoice.jpg" aspectRatio={210 / 297} />
```

:::

| 문서                 | `aspectRatio`  |
| -------------------- | -------------- |
| A4 용지, 세로        | `210 / 297`    |
| US Letter 용지, 세로 | `8.5 / 11`     |
| 신분증 카드, 가로    | `85.6 / 53.98` |

가로 방향 용지라면 `297 / 210`처럼 숫자를 바꾸세요. 비율은 화면에 보이는 페이지에 적용되므로, 사진이 옆으로 누워 있다면 보정하기 전에 [‘왼쪽으로 회전’](./rotate-and-flip)으로 돌리세요.

## 사진 밖으로 잘린 모서리

문서의 모서리가 사진 밖으로 나갈 때가 있습니다. 핸들은 이미지 안에 머무르므로, 그 핸들은 내용이 남는 쪽 문서 가장자리를 따라 사진 테두리에 놓으세요. 마지막 몇 줄이 조금 기울고 비율 추정도 나빠지지만, [`aspectRatio`](../../reference/options#aspectratio)로 바로잡을 수 있습니다.

[플레이그라운드](../../playground)에 모서리가 잘린 예시 영수증이 있어 직접 해 볼 수 있습니다.

## 코드에서 쓰기

‘기울기 보정’은 [`openTool('perspective')`](../../reference/methods#opentool)로 열고 [`confirmTool()`](../../reference/methods#confirmtool)이나 [`cancelTool()`](../../reference/methods#canceltool)로 닫습니다.

```ts
pic.edit()
pic.openTool('perspective')
pic.setPaper({ size: 'a4' })

// 나중에, 직접 만든 버튼에서
pic.confirmTool()
```

도구가 열려 있는 동안 [`setPaper()`](../../reference/methods#setpaper)로 용지 크기를 고릅니다. `confirmTool()`은 뷰어가 문서를 찾거나 모서리가 움직일 때까지 기다리며, 언제 할 수 있는지는 [상태](../../reference/state)의 `canConfirm`이 알려 줍니다.
