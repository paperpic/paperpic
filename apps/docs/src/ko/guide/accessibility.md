# 접근성

사람들은 마우스, 손가락, 키보드, 스크린 리더로 문서를 읽고 고칩니다. PaperPic은 WCAG 2.2 AA를 목표로 하며, 대부분의 작업이 이미 들어 있습니다. 이 페이지는 PaperPic이 하는 일과 앱이 더해야 할 일을 설명합니다.

## 앱이 제공하는 것

- **설명.** ‘11월 5일 영수증’처럼 [`alt`](../reference/options#alt)를 전달하세요. 스크린 리더가 이미지 이름으로 읽어 줍니다.
- **사용자 언어의 텍스트.** 스크린 리더는 버튼과 변화를 읽어 주므로, [`labels`](./labels)로 번역하세요.
- **직접 만든 컨트롤이 있다면 그 지원.** `toolbar: false`에서는 직접 만든 버튼이 기본 버튼을 대신하므로, 고유한 이름과 키보드 지원이 필요합니다.
- **보이는 포커스.** CSS가 뷰어의 포커스 윤곽선을 가리지 않게 하세요.

## 키보드

뷰어에 포커스가 있을 때:

| 키                           | 동작                                                       |
| ---------------------------- | ---------------------------------------------------------- |
| `+`와 `-`                    | 확대와 축소                                                |
| 화살표 키                    | 이동                                                       |
| `0`                          | 이미지 전체 맞추기                                         |
| `Ctrl+Z`                     | 실행 취소                                                  |
| `Ctrl+Shift+Z` 또는 `Ctrl+Y` | 다시 실행                                                  |
| `Enter`                      | 열린 도구를 확정, 없으면 변경을 적용                       |
| `Esc`                        | 선택한 모서리를 해제, 열린 도구를 닫기, 없으면 변경을 취소 |

macOS에서는 `Cmd`가 `Ctrl`처럼 동작합니다. 변경을 취소하기 전에 `Esc`는 확인을 요청합니다. `toolbar: false`에서는 이를 여러분의 인터페이스에 맡깁니다.

- **도구 모음과 편집 바.** Tab으로 각 바에 들어가고, 바 안에서는 화살표 키로 버튼을 옮겨 다니며, `Home`과 `End`로 첫 버튼과 마지막 버튼으로 갑니다.
- **모서리 핸들.** ‘자르기’나 ‘기울기 보정’이 열려 있으면 Tab으로 핸들을 오가고, 화살표 키로 포커스가 있는 핸들을 화면 1픽셀씩, Shift와 함께 10픽셀씩 옮깁니다.
- **눈금자.** ‘조정’과 ‘정리’의 눈금자는 기본 슬라이더입니다. 화살표 키, `Page Up`, `Page Down`, `Home`, `End`로 움직입니다. `Enter`는 ‘완료’처럼 값을 남기고, `Esc`는 값을 남기지 않고 도구를 닫습니다.

## 스크린 리더

- 이미지는 이미지 역할을 가지며, `alt`가 이름이 됩니다. `alt`가 없으면 스크린 리더는 이미지를 건너뜁니다.
- 도구 모음과 편집 바에는 ‘이미지 컨트롤’, ‘편집 컨트롤’처럼 고유한 이름이 있습니다.
- 포커스만으로는 알 수 없는 변화를 모두 알립니다. 확대/축소 배율, 편집 모드 시작, 옮긴 모서리의 위치, 눈금자 값, 적용 결과입니다.
- ‘정리’의 스위치는 스위치 역할을 가집니다. 화면에서 점으로 표시되는 사용 중인 도구는 ‘사용 중’으로 설명됩니다.

## 터치스크린

- `pointer: coarse`에서는 버튼과 모서리 핸들이 최소 44픽셀입니다.
- 손가락으로 모서리를 끄는 동안 돋보기가 손가락 아래 영역을 보여 줍니다.
- 모서리는 끌지 않고도 옮길 수 있습니다. 핸들을 누른 다음 옮길 위치를 탭하세요. 마우스로도 됩니다.
- 이미지가 맞춰져 있는 동안에는 한 손가락이 페이지를 스크롤하므로, 뷰어 안에 갇히지 않습니다. 확대하면 이미지를 이동합니다.

## 설정

- **동작 줄이기.** `prefers-reduced-motion: reduce`에서는 버튼 상태가 전환 효과 없이 바뀝니다.
- **강제 색상.** Windows 고대비 같은 강제 색상 모드에서도 눌린 버튼과 주요 동작에 보이는 윤곽선이 남습니다.
- **다크 모드.** 색은 페이지의 `color-scheme`을 따르며, 이 값은 시스템을 따르게 할 수도 있습니다. [스타일](./styling#dark-mode)을 참고하세요.
