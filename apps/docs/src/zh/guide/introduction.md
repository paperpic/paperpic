# 什么是 PaperPic？

文档照片往往是歪的，带着阴影，还有大片背景。PaperPic 在可以缩放的查看器中显示它们，并像扫描应用一样，让人们在你的应用保存之前矫正和清理每张照片。

## 它能做什么

- **查看。** 用按钮、滚轮或双指缩放，平移图片，让整张图片、图片宽度或高度适合查看器。只读查看器还可以旋转图片。
- **编辑。** 在编辑模式中，用户可以裁剪、矫正斜着拍的照片、旋转、翻转、调整亮度和对比度，并把文档清理成黑白。在用户应用修改之前，每项修改都可以撤销。
- **交付。** 应用会以完整分辨率计算结果，并以 `Blob` 的形式交给你的代码。下载按钮也可以保存它。

每一步都只在用户要求时发生。照片不会自己改变。

## 它不做什么

- 它不上传任何东西。如何处理结果由你的应用决定。
- 它不打开 PDF 文件，只打开图片。
- 它不会自己找到文档的边缘：由用户拖动四个角。

## 包

| 包                | 适用于                      |
| ----------------- | --------------------------- |
| `@paperpic/core`  | 原生 JavaScript，或任何框架 |
| `@paperpic/vue`   | Vue 3.5 或更高版本          |
| `@paperpic/react` | React 19 或更高版本         |

三个包的选项、事件和方法相同，核心没有运行时依赖。编辑在 Web Worker 中运行，因此处理大照片时页面依然流畅。
