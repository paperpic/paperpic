# 遮盖

文档照片有时会拍到不该显示的内容：账号、签名、背景里的人脸。“遮盖”用纯黑或纯白盖住一个水平或倾斜的矩形，结果中不再包含它下面的内容。

<Demo src="/samples/receipt.jpg" alt="一张收据" :tools="['redact']" />

## 使用方法

1. 按“编辑”，再按“遮盖”。图片中间会出现一条横带，每个角都有一个手柄。
2. 在要遮盖的内容上画出区域：在图片的任意位置（包括横带上），从区域的一个角拖到对角。之后拖动区域可以移动它，用它上方的手柄旋转，让它贴合倾斜的一行文字；拖动四个角可以改变大小。区域以半透明的颜色显示，方便你把它放在正确的文字上。
3. 在面板中选择“黑色”或“白色”。
4. 按“完成”或 `Enter`，把区域加入修改。“取消此工具”或 `Esc` 会关闭“遮盖”，不做任何更改。

只有在放置区域之前才能画。一旦画出、移动、旋转区域或改变其大小，在图片其余部分拖动就会重新平移图片，以免意外替换区域。在此之前，可以用两根手指平移放大的图片，或在焦点位于图片上时使用方向键。如果不拖动，横带就是区域：用键盘移动它，或先按它再点目标位置。

每按一次“完成”就加入一个区域，要遮盖其他部分，请再次打开“遮盖”。按“撤销”会移除最后一个区域，颜色会保留给下一个区域。角点手柄的用法与“[裁剪](./crop)”相同：可以拖动，可以先按手柄再点目标位置，也可以用键盘移动。在区域上方的手柄上，方向键将它旋转 1 度，按住 Shift 旋转 10 度。拖动时会吸附到水平。

## 保证的内容 {#guarantees}

- 区域在所有其他修改之后才盖上，因此“调整”和“清理”不会让它的黑色或白色变淡。
- 区域会跟随之后的修改：旋转、翻转或裁剪会让它随图片移动，“矫正”会让它随页面变形。
- 边缘碰到的每个像素都会盖住，哪怕只碰到一部分；在透明的 PNG 中也是不透明的。
- 应用修改时，区域会以纯色像素写入结果，因此文件中不会保留被盖住的任何内容。

在应用修改之前，查看器会保留原图，所以用“撤销”能找回区域盖住的内容。请始终分享应用修改后的结果，不要分享原图。

## 通过代码使用

“遮盖”默认在编辑栏中，在 [`tools`](../../reference/options#tools) 中的 id 是 `'redact'`。使用 `toolbar: false` 时，用 [`openTool()`](../../reference/methods#opentool) 打开它，用 [`setRedaction()`](../../reference/methods#setredaction) 选择颜色，再用 [`confirmTool()`](../../reference/methods#confirmtool) 或 [`cancelTool()`](../../reference/methods#canceltool) 关闭它：

```ts
pic.edit()
pic.openTool('redact')
pic.setRedaction({ color: 'white' })

// 稍后，在你自己的按钮中
pic.confirmTool()
```

[状态](../../reference/state)中的 `redaction` 保存当前使用的颜色。
