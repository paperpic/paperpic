# 调整

光线不足时拍的照片会偏暗或发灰。“调整”在保留颜色的同时修改亮度和对比度，适用于不应变成黑白的文档，例如彩色表单或照片。

## 使用方法

1. 按“编辑”，再按“调整”。它的面板会代替工具出现：一把刻度尺，以及用来选择刻度尺修改哪种色调的“亮度”和“对比度”。
2. 拖动刻度尺。拖动时预览随之变化。选择“对比度”，即可用同一把刻度尺修改另一种色调。
3. 按“完成”，两种色调会作为一项修改保留下来，“撤销”可以去掉它。“取消此工具”让图片保持原样。

刻度尺的中间位置保持图片原样，指针会停在中间，因此很容易回到未修改的状态。屏幕阅读器会朗读 -100 到 100 的数值，例如“亮度 +30”。“调整”以及面板中每种色调上的圆点，表示该值不为 0。

“调整”在其他修改之后进行，因此“裁剪”和“矫正”显示的是调整后的图片。

## 用“调整”还是“清理”？

| “调整”                   | [“清理”](./clean-up) |
| ------------------------ | -------------------- |
| 保留颜色和灰度           | 把文档变成黑白       |
| 适合彩色表单、印章和照片 | 适合纸上的文字       |
| 保留原图格式             | 输出 PNG             |

开启“清理”时，“调整”不可用，因为清理后的文档有自己的色调。

## 通过代码使用

[`setAdjustments()`](../../reference/methods#setadjustments) 接受 -1 到 1 的值，0 表示不变，[`getState()`](../../reference/methods#getstate) 会在 `adjustments` 中返回它们：

```ts
pic.edit()
pic.setAdjustments({ brightness: 0.2, contrast: 0.3 })
```

“调整”打开时，`setAdjustments()` 会改变面板显示的值，[`confirmTool()`](../../reference/methods#confirmtool) 会把它作为一项修改保留。

在 [`tools`](../../reference/options#tools) 选项中，“调整”是 `'adjust'`。
