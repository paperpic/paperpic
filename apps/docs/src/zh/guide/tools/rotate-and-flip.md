# 旋转和翻转

手机常常把文档照片存成横着或倒着的，有些扫描件还是镜像的。“向左旋转”和“翻转”可以纠正方向，图片的其他部分保持不变。

## 旋转

在编辑栏中，“向左旋转”会像相册一样把图片逆时针旋转四分之一圈。按两次是半圈，按三次相当于顺时针旋转四分之一圈。

旋转是一项修改：“撤销”可以去掉它，“应用”会让它生效。旋转四次后图片回到原来的方向，这时没有可应用的内容。

通过代码时，[`rotate()`](../../reference/methods#rotate) 传入 `1` 顺时针旋转，传入 `-1` 逆时针旋转：

```ts
pic.rotate(1)
pic.rotate(-1)
```

## 翻转

“翻转”按显示的样子把图片左右镜像，因此旋转四分之一圈之后，它在屏幕上仍然是左右镜像。要把图片上下颠倒，先翻转再旋转两次。

相互抵消的翻转和旋转不会留下可应用的内容。通过代码时，调用 [`flip()`](../../reference/methods#flip)。

## 在只读查看器中

设置 [`editable: false`](../viewer#read-only) 时，工具栏中有“向左旋转”和“向右旋转”按钮。它们只旋转显示的图片：不会保存任何东西，也不会触发 `apply` 事件。[`rotate()`](../../reference/methods#rotate) 可以通过代码做同样的事。只读查看器没有“翻转”。

## Id

在 [`tools`](../../reference/options#tools) 选项中，“向左旋转”是 `'rotate'`，“翻转”是 `'flip'`。
