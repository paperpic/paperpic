# 裁剪

文档照片常常会拍进桌面、手或周围的其他纸张。“裁剪”保留包含文档的矩形，去掉其余部分。

## 使用方法

1. 按“编辑”，再按“裁剪”。图片中会出现一个矩形，每个角都有一个手柄。
2. 拖动四个角，直到矩形框住文档。缩放按钮依然可用，你可以放大后精确放置。
3. 按“完成”或 `Enter`，把裁剪加入修改。“取消此工具”或 `Esc` 会关闭“裁剪”而不做任何改变。

裁剪和其他修改一样：“撤销”可以去掉它，“应用”会让它生效。

## 角点手柄

- 手柄始终留在图片内，矩形永远不会翻转。
- 在触摸屏上拖动角时，放大镜会显示手指下方的区域，手指不会挡住角落的位置。
- 使用键盘时，Tab 在手柄之间切换，方向键把获得焦点的手柄移动 1 个屏幕像素，按住 Shift 则移动 10 个。屏幕阅读器会朗读每次移动。

## 用“裁剪”还是“矫正”？

“裁剪”保留的是原样的矩形。在斜着拍的照片里，文档看起来像梯形，矩形无法贴合。这种照片请使用[“矫正”](./straighten)：它分别移动每个角，把页面变平。

## 通过代码使用

“裁剪”默认在编辑栏中，在 [`tools`](../../reference/options#tools) 中的 id 为 `'crop'`。设置 `toolbar: false` 时，用 [`openTool()`](../../reference/methods#opentool) 打开，用 [`confirmTool()`](../../reference/methods#confirmtool) 或 [`cancelTool()`](../../reference/methods#canceltool) 关闭：

```ts
pic.edit()
pic.openTool('crop')

// 稍后，从你自己的按钮调用
pic.confirmTool()
```
