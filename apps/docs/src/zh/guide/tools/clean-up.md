# 清理

“清理”选择图片的效果：原始色调、灰度或黑白。它在 API 中的 id 是 `finish`。

纸上的文字在黑白下最易读，但照片里有阴影、不均匀的光线和发灰的纸张。黑白把每个像素与周围比较，判断它是墨迹还是纸张，所以阴影和不均匀的光线会消失，文字保持清晰。灰度保留所有色调，只去掉颜色，适合带有照片或印章、黑白会丢失细节的文档。

## 使用方法

1. 点击“编辑”，再点击“清理”。它的面板取代工具，显示三种效果：“原图”“灰度”和“黑白”。它以黑白打开，所以预览变成黑白，“灵敏度”刻度尺可以使用。
2. 拖动刻度尺。灵敏度越高，变暗的像素越多，可以找回浅淡或磨损的文字。灵敏度越低，页面越干净，不会透出背面的印刷。
3. 想要灰度图片就选“灰度”，想保留照片的色调就选“原图”。刻度尺只在黑白下可用。
4. 点击“完成”把它保留为一项修改，或点击“取消此工具”让图片保持原样。

“清理”已经是一项修改时，会以它的效果再次打开。要关闭它，选择“原图”：之后的修改会保留。而“撤销”还会删除那些修改。

“清理”总是在其他修改之后进行。“裁剪”显示带有效果的图片，即最终的样子。“矫正”显示没有黑白的图片，因为在清理后的页面上很难找到纸张的边缘，灰度则会保留。

[“调整”](./adjust)可以和在它之后进行的灰度一起使用，但在有自己色调的黑白下不可用。

## 柔和度

[`softness`](../../reference/options#softness) 设置黑白在字母边缘保留多少灰色，范围 0 到 1，默认为 0.25。少量灰色能让边缘更平滑，小字更易读。用 `0` 得到严格的黑白，文件更小，但细笔画会断开。

## 结果的格式

黑白图片是 PNG，因为 JPEG 会在清晰的边缘周围产生杂点。灰度图片保留来源的格式。[`output`](../../reference/options#output) 选项可以选择其他格式。

## 通过代码使用

[`setFinish()`](../../reference/methods#setfinish) 选择效果：`'original'`、`'gray'` 或表示黑白的 `'mono'`，并设置黑白的灵敏度，范围 0 到 1，默认为 0.5。[`getState()`](../../reference/methods#getstate) 在 `finish` 中返回这两项：

```ts
pic.edit()
pic.setFinish({ mode: 'mono', sensitivity: 0.6 })
```

“清理”打开时，`setFinish()` 会改变它的面板显示的内容，[`confirmTool()`](../../reference/methods#confirmtool) 会把它作为一项修改保留。
