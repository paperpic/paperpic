# 无障碍

人们用鼠标、手指、键盘或屏幕阅读器来阅读和修正文档。PaperPic 以 WCAG 2.2 AA 为目标，大部分工作已经内置。本页说明它做了什么，以及你的应用需要补充什么。

## 你的应用需要提供的

- **描述。** 传入 [`alt`](../reference/options#alt)，例如“11 月 5 日的收据”。屏幕阅读器会把它作为图片的名称朗读。
- **用户语言的文本。** 屏幕阅读器会朗读按钮和变化，所以请用 [`labels`](./labels) 翻译它们。
- **你自己的控件（如果有）。** 设置 `toolbar: false` 时，你创建的按钮会替代内置按钮，它们需要自己的名称和键盘支持。
- **可见的焦点。** 不要让你的 CSS 隐藏查看器的焦点轮廓。

## 键盘

焦点在查看器上时：

| 按键                       | 操作                         |
| -------------------------- | ---------------------------- |
| `+` 和 `-`                 | 放大和缩小                   |
| 方向键                     | 平移                         |
| `0`                        | 让整张图片适合               |
| `Ctrl+Z`                   | 撤销                         |
| `Ctrl+Shift+Z` 或 `Ctrl+Y` | 重做                         |
| `Enter`                    | 确认打开的工具，否则应用修改 |
| `Esc`                      | 关闭打开的工具，否则取消修改 |

在 macOS 上，`Cmd` 与 `Ctrl` 作用相同。取消修改前，`Esc` 会请求确认。设置 `toolbar: false` 时，它把这件事交给你的界面。

- **工具栏和编辑栏。** Tab 进入每个栏，在栏内用方向键在按钮之间移动，`Home` 和 `End` 跳到第一个和最后一个按钮。
- **角点手柄。** 打开“裁剪”或“矫正”时，Tab 在手柄之间切换，方向键把获得焦点的手柄移动 1 个屏幕像素，按住 Shift 则移动 10 个。
- **滑块。** 方向键移动“调整”和“清理”的滑块。

## 屏幕阅读器

- 图片具有图片角色，以 `alt` 为名称。
- 工具栏和编辑栏有自己的名称，例如“图片控件”和“编辑控件”。
- 仅凭焦点看不出的每一项变化都会被播报：缩放级别、编辑模式开始、被移动的角的位置、滑块的值以及应用的结果。

## 触摸屏

- 在 `pointer: coarse` 下，按钮和角点手柄至少为 44 像素。
- 手指拖动角时，放大镜会显示手指下方的区域。
- 图片处于适合状态时，单指会滚动页面，因此查看器不会把人困在里面。放大后则平移图片。

## 偏好设置

- **减少动态效果。** 在 `prefers-reduced-motion: reduce` 下，按钮切换状态时没有过渡。
- **强制颜色。** 在 Windows 高对比度等强制颜色模式下，按下的按钮和主要操作仍保留可见的轮廓。
- **深色模式。** 颜色跟随页面的 `color-scheme`，而它也可以跟随系统。参见[样式](./styling#dark-mode)。
