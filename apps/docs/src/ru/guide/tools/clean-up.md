# Очистить

Текст на бумаге лучше всего читается в чёрно-белом виде, но на фотографии есть тени, неравномерный свет и серая бумага. «Очистить» сравнивает каждый пиксель с его окружением, чтобы решить, чернила это или бумага, поэтому тени и неравномерный свет исчезают, а текст остаётся чётким. Его id в API — `threshold`.

Сначала выровняйте чек, затем очистите его.

## Как пользоваться

1. Нажмите «Редактировать», затем «Очистить». Вместо инструментов появятся его элементы управления: предпросмотр станет чёрно-белым, и появится шкала «Чувствительность».
2. Перетащите шкалу. Более высокая чувствительность затемняет больше пикселей и возвращает бледный или стёртый текст. Более низкая даёт более чистую страницу, без того, что просвечивает с обратной стороны.
3. Нажмите «Готово», чтобы сохранить его как одно изменение, или «Отменить этот инструмент», чтобы оставить изображение как было.

Чтобы выключить «Очистить», который уже стал изменением, откройте его снова: переключатель рядом со шкалой выключает его, а изменения, сделанные после, остаются. «Отменить» сначала убрало бы эти изменения.

«Очистить» всегда выполняется после остальных изменений. «Обрезать» показывает изображение очищенным, каким оно будет. «Выровнять» показывает его без «Очистить», потому что на очищенной странице трудно найти края бумаги.

## Мягкость

[`softness`](../../reference/options#softness) задаёт, сколько серого «Очистить» оставляет по краям букв, от 0 до 1, по умолчанию 0.25. Немного серого сглаживает края и облегчает чтение мелкого текста. Используйте `0` для строгого чёрно-белого, которое даёт файлы меньше, но ломает тонкие штрихи.

## Формат результата

Очищенное изображение сохраняется в PNG, потому что JPEG добавил бы артефакты вокруг его чётких краёв. Опция [`output`](../../reference/options#output) может выбрать другой формат.

## Из кода

[`setThreshold()`](../../reference/methods#setthreshold) включает или выключает «Очистить» и задаёт его чувствительность от 0 до 1, по умолчанию 0.5. [`getState()`](../../reference/methods#getstate) возвращает оба значения в `threshold`:

```ts
pic.edit()
pic.setThreshold({ enabled: true, sensitivity: 0.6 })
```

Пока «Очистить» открыт, `setThreshold()` меняет то, что он показывает, а [`confirmTool()`](../../reference/methods#confirmtool) сохраняет это как одно изменение.
