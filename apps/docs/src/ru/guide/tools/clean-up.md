# Очистить

«Очистить» выбирает обработку изображения: исходные тона, серый или чёрно-белый режим. Его id в API — `finish`.

Текст на бумаге лучше всего читается в чёрно-белом виде, но на фотографии есть тени, неравномерный свет и серая бумага. Чёрно-белый режим сравнивает каждый пиксель с его окружением, чтобы решить, чернила это или бумага, поэтому тени и неравномерный свет исчезают, а текст остаётся чётким. Серый сохраняет все тона и убирает только цвет — для документов с фотографиями или печатями, которые чёрно-белый режим потерял бы.

Сначала выровняйте чек, затем очистите его.

## Как пользоваться

1. Нажмите «Редактировать», затем «Очистить». Его элементы управления занимают место инструментов, с тремя вариантами обработки: «Оригинал», «Серый» и «Чёрно-белый». Он открывается в чёрно-белом режиме, поэтому предпросмотр становится чёрно-белым, а шкала «Чувствительность» работает.
2. Перетащите шкалу. Более высокая чувствительность затемняет больше пикселей и восстанавливает бледный или стёртый текст. Более низкая даёт более чистую страницу, без печати, просвечивающей с обратной стороны.
3. Выберите «Серый» для серого изображения или «Оригинал» для тонов фотографии. Шкала работает только в чёрно-белом режиме.
4. Нажмите «Готово», чтобы сохранить это как одно изменение, или «Отменить этот инструмент», чтобы оставить изображение как было.

Когда «Очистить» уже стало изменением, оно снова открывается со своей обработкой. Чтобы выключить его, выберите «Оригинал»: изменения, сделанные после, остаются. Отмена же убрала бы и эти изменения.

«Очистить» всегда выполняется после остальных изменений. «Обрезать» показывает изображение с его обработкой, каким оно будет. «Выровнять» показывает его без чёрно-белого режима, потому что края бумаги трудно найти на очищенной странице, и сохраняет серый.

[«Настроить»](./adjust) работает с серым, который идёт после него, и недоступен в чёрно-белом режиме, у которого свои тона.

## Мягкость

[`softness`](../../reference/options#softness) задаёт, сколько серого чёрно-белый режим оставляет по краям букв, от 0 до 1, по умолчанию 0.25. Немного серого сглаживает края и делает мелкий текст разборчивее. Используйте `0` для строгого чёрно-белого, которое даёт файлы меньше, но ломает тонкие штрихи.

## Формат результата

Чёрно-белое изображение сохраняется в PNG, потому что JPEG добавил бы артефакты вокруг его резких краёв. Серое изображение сохраняет формат источника. Опция [`output`](../../reference/options#output) может выбрать другой формат.

## Из кода

[`setFinish()`](../../reference/methods#setfinish) выбирает обработку, `'original'`, `'gray'` или `'mono'` для чёрно-белого режима, и задаёт чувствительность чёрно-белого режима от 0 до 1, по умолчанию 0.5. [`getState()`](../../reference/methods#getstate) возвращает оба значения в `finish`:

```ts
pic.edit()
pic.setFinish({ mode: 'mono', sensitivity: 0.6 })
```

Пока «Очистить» открыт, `setFinish()` меняет то, что показывают его элементы управления, а [`confirmTool()`](../../reference/methods#confirmtool) сохраняет это как одно изменение.
