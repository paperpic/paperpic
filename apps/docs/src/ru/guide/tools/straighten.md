# Выровнять

Документ, снятый под углом, похож на трапецию: дальний край короче, а текст наклонён. «Выровнять» возвращает его к ровной прямоугольной странице, как после сканера. Его id в API — `perspective`.

## Как пользоваться

1. Нажмите «Редактировать», затем «Выровнять». Для каждого угла появится маркер — на документе, если просмотрщик [его найдёт](#finding-the-document).
2. Перетащите каждый маркер, который стоит не на месте, на его угол документа. Приблизьте изображение кнопками масштаба в его элементах управления, чтобы поставить их точно.
3. Если вы знаете бумагу, выберите её [формат](#paper-size): «A4», «Letter» или «Карта». «Авто» оценивает его.
4. Нажмите «Готово» или `Enter`. Просмотрщик покажет ровную страницу, обрезанную по четырём углам. Кнопка «Готово» становится доступной, когда просмотрщик находит документ или вы сдвигаете угол.

Маркеры работают как в [«Обрезать»](./crop): лупа на сенсорных экранах, нажатие и касание вместо перетаскивания, Tab и стрелки на клавиатуре. Четыре угла всегда образуют выпуклую фигуру, поэтому страницу всегда можно выровнять.

«Выровнять» показывает фотографию без чёрно-белого режима [«Очистить»](./clean-up), потому что на очищенной странице трудно найти края бумаги. После нажатия «Готово» чёрно-белый режим возвращается, а серый остаётся.

## Поиск документа {#finding-the-document}

Когда открывается «Выровнять», просмотрщик ищет документ на фотографии и ставит на него четыре угла, поэтому «Готово» можно нажать сразу. Поиск идёт в браузере, занимает доли секунды и ничего не меняет, пока вы не нажмёте «Готово».

Просмотрщик предлагает только то, в чём достаточно уверен. Если бумага сливается со столом или на фотографии нет документа, углы начинают внутри изображения и ждут пользователя. Угол, которого пользователь уже коснулся, никогда не сдвигается сам.

## Формат бумаги {#paper-size}

В элементах управления «Выровнять» есть форматы бумаги, которые дают результату точные пропорции этой бумаги:

| Выбор  | Пропорции                                                                       |
| ------ | ------------------------------------------------------------------------------- |
| Авто   | [`aspectRatio`](../../reference/options#aspectratio) или [оценка](#proportions) |
| A4     | 210 × 297 мм, такие же у A3 и A5                                                |
| Letter | 8,5 × 11 дюймов, US Letter                                                      |
| Карта  | 85,6 × 53,98 мм, удостоверение или банковская карта                             |

Формат задаёт только пропорции: он не двигает углы. Книжная или альбомная ориентация зависит от углов, поэтому выбирать её не нужно. Формат, который не совпадает с форматом документа, искажает его, поэтому «Выровнять» каждый раз открывается с «Авто».

Если четыре угла стоят на углах изображения, «Авто» ничего не меняет, а формат придаёт всему изображению пропорции этой бумаги.

## Пропорции {#proportions}

По фотографии нельзя узнать настоящую форму страницы, поэтому «Выровнять» оценивает её пропорции по положению углов на фотографии. Оценка хорошо подходит для снимков с обычного расстояния, но точной быть не может.

Оценка опирается на исходную фотографию, даже после обрезки или поворота в том же редактировании. Как только пользователь применяет изменения, результат считается новой фотографией, поэтому выравнивайте до применения.

Если вы знаете документ, задайте в [`aspectRatio`](../../reference/options#aspectratio) его ширину, делённую на высоту, и результат получит эти пропорции:

:::tabs key:framework
== JavaScript

```ts
const pic = new PaperPic(container, {
  src: '/invoice.jpg',
  aspectRatio: 210 / 297,
})
```

== Vue

```vue
<PaperPic src="/invoice.jpg" :aspect-ratio="210 / 297" />
```

== React

```tsx
<PaperPic src="/invoice.jpg" aspectRatio={210 / 297} />
```

:::

| Документ                           | `aspectRatio`  |
| ---------------------------------- | -------------- |
| Лист A4, книжная ориентация        | `210 / 297`    |
| Лист US Letter, книжная ориентация | `8.5 / 11`     |
| Удостоверение личности, альбомная  | `85.6 / 53.98` |

Для листа в альбомной ориентации поменяйте числа местами, например `297 / 210`. Пропорции применяются к странице так, как она видна на экране, поэтому фото, лежащее на боку, сначала поверните кнопкой [«Повернуть влево»](./rotate-and-flip), а потом выравнивайте.

## Углы, обрезанные краем фотографии

Иногда угол документа оказывается за пределами фотографии. Маркеры остаются внутри изображения, поэтому поставьте такой маркер на край фотографии, вдоль стороны документа, где сохраняется содержимое. Последние строки немного наклонятся, а оценка пропорций ухудшится, что можно исправить через [`aspectRatio`](../../reference/options#aspectratio).

В [песочнице](../../playground) есть пример чека с обрезанным углом, чтобы это попробовать.

## Из кода

«Выровнять» открывается через [`openTool('perspective')`](../../reference/methods#opentool) и закрывается через [`confirmTool()`](../../reference/methods#confirmtool) или [`cancelTool()`](../../reference/methods#canceltool):

```ts
pic.edit()
pic.openTool('perspective')
pic.setPaper({ size: 'a4' })

// Позже, из вашей собственной кнопки
pic.confirmTool()
```

Выберите формат бумаги через [`setPaper()`](../../reference/methods#setpaper), пока инструмент открыт. `confirmTool()` ждёт, пока просмотрщик не найдёт документ или не сдвинут угол, а `canConfirm` [состояния](../../reference/state) говорит, когда можно.
