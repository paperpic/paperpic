# Выровнять

Документ, снятый под углом, похож на трапецию: дальний край короче, а текст наклонён. «Выровнять» возвращает его к ровной прямоугольной странице, как после сканера. Его id в API — `perspective`.

<Demo src="/samples/receipt.jpg" alt="Кассовый чек" :tools="['perspective']" />

## Как пользоваться

1. Нажмите «Редактировать», затем «Выровнять». Для каждого угла появится маркер.
2. Перетащите каждый маркер на угол документа. Приблизьте изображение, чтобы поставить их точно.
3. Нажмите «Готово» или `Enter`. Просмотрщик покажет ровную страницу, обрезанную по четырём углам.

Маркеры работают как в [«Обрезать»](./crop): лупа на сенсорных экранах, Tab и стрелки на клавиатуре. Четыре угла всегда образуют выпуклую фигуру, поэтому страницу всегда можно выровнять.

## Пропорции

По фотографии нельзя узнать настоящую форму страницы, поэтому «Выровнять» оценивает её пропорции по положению углов на фотографии. Оценка хорошо подходит для снимков с обычного расстояния, но точной быть не может.

Оценка опирается на исходную фотографию, даже после обрезки или поворота в том же редактировании. Как только пользователь применяет изменения, результат считается новой фотографией, поэтому выравнивайте до применения.

Если вы знаете документ, задайте в [`aspectRatio`](../../reference/options#aspectratio) его ширину, делённую на высоту, и результат получит эти пропорции:

:::tabs key:framework
== JavaScript

```ts
const pic = new PaperPic(container, {
  src: '/invoice.jpg',
  aspectRatio: 210 / 297,
})
```

== Vue

```vue
<PaperPic src="/invoice.jpg" :aspect-ratio="210 / 297" />
```

== React

```tsx
<PaperPic src="/invoice.jpg" aspectRatio={210 / 297} />
```

:::

| Документ                           | `aspectRatio`  |
| ---------------------------------- | -------------- |
| Лист A4, книжная ориентация        | `210 / 297`    |
| Лист US Letter, книжная ориентация | `8.5 / 11`     |
| Удостоверение личности, альбомная  | `85.6 / 53.98` |

Для листа в альбомной ориентации поменяйте числа местами, например `297 / 210`.

## Углы, обрезанные краем фотографии

Иногда угол документа оказывается за пределами фотографии. Маркеры остаются внутри изображения, поэтому поставьте такой маркер на край фотографии, вдоль стороны документа, где сохраняется содержимое. Последние строки немного наклонятся, а оценка пропорций ухудшится, что можно исправить через [`aspectRatio`](../../reference/options#aspectratio).

В [песочнице](../../playground) есть пример чека с обрезанным углом, чтобы это попробовать.

## Из кода

«Выровнять» открывается через [`openTool('perspective')`](../../reference/methods#opentool) и закрывается через [`confirmTool()`](../../reference/methods#confirmtool) или [`cancelTool()`](../../reference/methods#canceltool):

```ts
pic.edit()
pic.openTool('perspective')

// Позже, из вашей собственной кнопки
pic.confirmTool()
```
