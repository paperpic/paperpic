# Настроить

Фотографии при плохом освещении получаются тёмными или серыми. «Настроить» меняет яркость и контрастность и сохраняет цвета — для документов, которые не должны становиться чёрно-белыми, например цветных бланков или фотографий.

## Как пользоваться

1. Нажмите «Редактировать», затем «Настроить». На панели редактирования появятся два ползунка: «Яркость» и «Контрастность».
2. Перетащите ползунок. Предпросмотр меняется во время перетаскивания, а когда вы отпускаете ползунок, остаётся одно изменение, которое убирает «Отменить».
3. Нажмите «Настроить» ещё раз, чтобы скрыть ползунки.

Середина каждого ползунка оставляет изображение как есть, а ползунок, возвращённый в середину, не считается изменением. Программы чтения с экрана озвучивают значение от -100 до 100, например «Яркость +30».

«Настроить» выполняется после остальных изменений, поэтому «Обрезать» и «Выровнять» показывают изображение с ним.

## «Настроить» или «Очистить»?

| «Настроить»                               | [«Очистить»](./clean-up)    |
| ----------------------------------------- | --------------------------- |
| Сохраняет цвета и оттенки серого          | Делает документ чёрно-белым |
| Для цветных бланков, печатей и фотографий | Для текста на бумаге        |
| Сохраняет формат исходного изображения    | Даёт PNG                    |

Пока включено «Очистить», «Настроить» недоступно, потому что у очищенного документа свои тона.

## Из кода

[`setAdjustments()`](../../reference/methods#setadjustments) принимает значения от -1 до 1, где 0 ничего не меняет, а [`getState()`](../../reference/methods#getstate) возвращает их в `adjustments`:

```ts
pic.edit()
pic.setAdjustments({ brightness: 0.2, contrast: 0.3 })
```

В опции [`tools`](../../reference/options#tools) «Настроить» — это `'adjust'`.
