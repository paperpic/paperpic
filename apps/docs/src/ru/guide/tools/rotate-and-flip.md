# Поворот и отражение

Телефоны часто сохраняют фотографию документа боком или вверх ногами, а некоторые сканы выходят зеркальными. «Повернуть влево» и «Отразить» исправляют ориентацию и не трогают остальное изображение.

## Поворот

На панели редактирования «Повернуть влево» поворачивает изображение на четверть оборота против часовой стрелки, как в галереях фотографий. Нажмите дважды для половины оборота или трижды для четверти оборота по часовой стрелке.

Поворот — это изменение: «Отменить» убирает его, а «Применить» делает постоянным. Четыре поворота возвращают изображение в исходное положение, и тогда применять нечего.

Из кода [`rotate()`](../../reference/methods#rotate) поворачивает по часовой стрелке с `1` и против часовой с `-1`:

```ts
pic.rotate(1)
pic.rotate(-1)
```

## Отражение

«Отразить» зеркально отражает изображение слева направо так, как оно показано, поэтому после четверти оборота оно по-прежнему отражается слева направо на экране. Чтобы перевернуть изображение вверх ногами, отразите его и поверните дважды.

Отражения и повороты, которые компенсируют друг друга, не оставляют ничего для применения. Из кода вызовите [`flip()`](../../reference/methods#flip).

## В просмотрщике только для чтения

С [`editable: false`](../viewer#read-only) на панели инструментов есть кнопки «Повернуть влево» и «Повернуть вправо». Они только поворачивают изображение на экране: ничего не сохраняется, и событие `apply` не возникает. [`rotate()`](../../reference/methods#rotate) делает то же из кода. В просмотрщике только для чтения нет «Отразить».

## Id

В опции [`tools`](../../reference/options#tools) «Повернуть влево» — это `'rotate'`, а «Отразить» — `'flip'`.
