# Что такое PaperPic?

Фотографии документов приходят перекошенными, с тенями и большим фоном. PaperPic показывает их в просмотрщике, который можно масштабировать, и позволяет выровнять и очистить каждую фотографию, прежде чем ваше приложение её сохранит, как это сделало бы приложение-сканер.

## Что он умеет

- **Просмотр.** Масштаб кнопками, колесом мыши или щипком, перемещение изображения и подгонка всего изображения, его ширины или высоты. Просмотрщик только для чтения также может поворачивать изображение.
- **Редактирование.** В режиме редактирования пользователь может обрезать, выровнять снятую под углом фотографию, повернуть, отразить, настроить яркость и контрастность и очистить документ до чёрно-белого. Каждое изменение можно отменить, пока пользователь не применит изменения.
- **Результат.** Применение вычисляет результат в полном разрешении и передаёт его вашему коду как `Blob`. Кнопка скачивания тоже может его сохранить.

Каждый шаг выполняется, только когда пользователь его просит. Ничто не меняет фотографию само по себе.

## Чего он не делает

- Ничего не загружает на сервер. Что делать с результатом, решает ваше приложение.
- Не открывает PDF-файлы, только изображения.
- Сам не находит края документа: пользователь перетаскивает углы.

## Пакеты

| Пакет             | Для чего                              |
| ----------------- | ------------------------------------- |
| `@paperpic/core`  | Чистый JavaScript или любой фреймворк |
| `@paperpic/vue`   | Vue 3.5 и новее                       |
| `@paperpic/react` | React 19 и новее                      |

У всех трёх одинаковые опции, события и методы, а у ядра нет зависимостей во время выполнения. Редактирование выполняется в Web Worker, поэтому страница остаётся отзывчивой даже с большими фотографиями.
