# Редактирование

Фотографию документа обычно нужно немного поправить, прежде чем её стоит сохранять. Режим редактирования собирает эти правки вместе: пользователь вносит изменения, проверяет их и применяет все сразу. В [песочнице](../playground) можно попробовать весь режим редактирования.

## Как проходит редактирование

1. Пользователь нажимает «Редактировать» — карандаш на панели инструментов. Внизу просмотрщика появляется панель редактирования.
2. Каждый инструмент панели редактирования добавляет изменение, которое просмотрщик сразу показывает. «Отменить» и «Повторить» перемещаются по изменениям.
3. «Применить» вычисляет результат и возвращает к просмотру. «Отмена» отбрасывает изменения и, если они есть, сначала спрашивает.

До применения ничто не меняет изображение. До этого изменения — это список, который просмотрщик показывает в предпросмотре.

## Инструменты

| Инструмент                                   | Что делает                                               | Id            |
| -------------------------------------------- | -------------------------------------------------------- | ------------- |
| [«Обрезать»](./tools/crop)                   | Оставляет часть изображения внутри четырёх углов         | `crop`        |
| [«Выровнять»](./tools/straighten)            | Превращает снятую под углом фотографию в ровную страницу | `perspective` |
| [«Повернуть влево»](./tools/rotate-and-flip) | Поворачивает изображение на четверть оборота влево       | `rotate`      |
| [«Отразить»](./tools/rotate-and-flip)        | Отражает изображение слева направо                       | `flip`        |
| [«Настроить»](./tools/adjust)                | Меняет яркость и контрастность                           | `adjust`      |
| [«Очистить»](./tools/clean-up)               | Делает документ чётким чёрно-белым, без теней            | `threshold`   |

Опция [`tools`](../reference/options#tools) выбирает, какие из них предлагает панель редактирования:

:::tabs key:framework
== JavaScript

```ts
const pic = new PaperPic(container, {
  src: '/receipt.jpg',
  tools: ['crop', 'perspective', 'rotate'],
})
```

== Vue

```vue
<script setup lang="ts">
import type { ToolId } from '@paperpic/vue'
import { PaperPic } from '@paperpic/vue'

const tools: ToolId[] = ['crop', 'perspective', 'rotate']
</script>

<template>
  <PaperPic src="/receipt.jpg" :tools />
</template>
```

== React

```tsx
import type { ToolId } from '@paperpic/react'
import { PaperPic } from '@paperpic/react'

const tools: ToolId[] = ['crop', 'perspective', 'rotate']

export function Receipt() {
  return <PaperPic src="/receipt.jpg" tools={tools} />
}
```

:::

У «Обрезать» и «Выровнять» есть собственное выделение, поэтому остальная панель редактирования ждёт, пока один из них открыт. «Готово» или `Enter` добавляет выделение к изменениям, а «Отменить этот инструмент» или `Esc` отбрасывает его.

## Предпросмотр и применение

Во время редактирования просмотрщик показывает изменения на копии изображения размером около 2 мегапикселей, чтобы оставаться быстрым с большими фотографиями. При сильном увеличении предпросмотр выглядит мягче результата. «Применить» вычисляет все изменения в полном разрешении или в [`maxOutputSize`](../reference/options#maxoutputsize) в Web Worker.

Применение нельзя прервать. Пока оно идёт, элементы управления заблокированы и показывается сообщение. Затем результат заменяет изображение на экране, история очищается, а просмотрщик возвращается в режим просмотра. Если применение не удалось, редактирование остаётся открытым, чтобы пользователь мог попробовать снова.

## Что получает ваш код

| Событие  | Когда                                                                   |
| -------- | ----------------------------------------------------------------------- |
| `change` | После каждого действия пользователя, с [состоянием](../reference/state) |
| `apply`  | Когда результат готов, с `{ blob, width, height, type }`                |
| `error`  | Когда применение не удалось или изображение не загрузилось              |

:::tabs key:framework
== JavaScript

```ts
pic.on('apply', ({ blob }) => upload(blob))
pic.on('error', ({ error }) => console.error(error))
```

== Vue

```vue
<PaperPic
  src="/receipt.jpg"
  @apply="({ blob }) => upload(blob)"
  @error="({ error }) => console.error(error)"
/>
```

== React

```tsx
<PaperPic
  src="/receipt.jpg"
  onApply={({ blob }) => upload(blob)}
  onError={({ error }) => console.error(error)}
/>
```

:::

## Что отбрасывает изменения

- «Отмена» после подтверждения пользователя или [`cancel()`](../reference/methods#cancel), который не спрашивает.
- Новый `src` во время редактирования.
- Изменение `editable` во время редактирования.

После применения повторная передача того же `src` ничего не делает, поэтому результат остаётся на экране. [`reload()`](../reference/methods#reload) возвращает оригинал.

## Клавиатура

Когда фокус на просмотрщике:

| Клавиша                     | Действие                                                   |
| --------------------------- | ---------------------------------------------------------- |
| `Ctrl+Z`                    | Отменить                                                   |
| `Ctrl+Shift+Z` или `Ctrl+Y` | Повторить                                                  |
| `Enter`                     | Подтвердить открытый инструмент, иначе применить изменения |
| `Esc`                       | Закрыть открытый инструмент, иначе отменить изменения      |

В macOS `Cmd` работает как `Ctrl`.
