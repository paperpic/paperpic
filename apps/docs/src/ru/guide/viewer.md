# Просмотрщик

Мелкий шрифт и длинные чеки трудно прочитать на экране с одного взгляда. Просмотрщик подгоняет изображение при загрузке и позволяет приблизить любую его часть.

<Demo src="/samples/receipt.jpg" alt="Кассовый чек" :editable="false" />

## Масштаб и перемещение

| Действие                              | Мышь и трекпад               | Сенсорный экран | Клавиатура |
| ------------------------------------- | ---------------------------- | --------------- | ---------- |
| Масштабировать                        | Колесо или щипок на трекпаде | Щипок           | `+` и `-`  |
| Перемещать                            | Перетаскивание               | Перетаскивание  | Стрелки    |
| Переключаться между подгонкой и 100 % | Двойной щелчок               | Двойное касание |            |
| Подогнать всё изображение             |                              |                 | `0`        |

Клавиатура работает, когда фокус на просмотрщике. Щипок масштабирует вокруг точки между пальцами.

Масштаб идёт от подгонки всего изображения, или 100 % для маленького изображения, до 800 %. Изображение, которое помещается, остаётся по центру, а то, что не помещается, перемещается до своих краёв.

При загрузке изображение целиком подгоняется под просмотрщик и сохраняет подгонку при изменении размера просмотрщика, пока пользователь не изменит масштаб вручную.

На длинной странице колесо масштабировало бы изображение вместо прокрутки страницы. Используйте там `wheelZoom: false`: кнопки, клавиатура и щипок на сенсорном экране продолжат масштабировать.

## Панель инструментов

Панель инструментов находится справа в просмотрщике и прокручивается, если просмотрщик слишком низкий для её кнопок.

| Кнопка                                | Что делает                                                                  |
| ------------------------------------- | --------------------------------------------------------------------------- |
| «Редактировать»                       | Открывает [режим редактирования](./editing). Скрыта при `editable: false`   |
| «Увеличить», «Уменьшить»              | Меняют масштаб на один шаг вокруг центра                                    |
| «По ширине», «По высоте»              | Подгоняют ширину, что удобно для длинных документов, или высоту             |
| «Повернуть влево», «Повернуть вправо» | Только в просмотрщике только для чтения: поворачивают изображение на экране |
| «Скачать»                             | Только при `download: true`: сохраняет изображение на экране                |

С `toolbar: false` панель инструментов и панель редактирования скрыты, и вы можете сделать свои элементы управления с помощью [методов](../reference/methods).

## Просмотрщик только для чтения

С `editable: false` кнопка «Редактировать» исчезает, а на панели инструментов появляются две кнопки, которые поворачивают изображение. Такой поворот меняет только отображение, и ничего не сохраняется. Используйте это для документов, которые нужно читать, но нельзя менять, например вложений в карточке записи.

:::tabs key:framework
== JavaScript

```ts
const pic = new PaperPic(container, {
  src: '/receipt.jpg',
  alt: 'Кассовый чек',
  editable: false,
})
```

== Vue

```vue
<PaperPic src="/receipt.jpg" alt="Кассовый чек" :editable="false" />
```

== React

```tsx
<PaperPic src="/receipt.jpg" alt="Кассовый чек" editable={false} />
```

:::

## Управление видом из кода

Методы [`zoomIn()`](../reference/methods#zoomin), [`zoomOut()`](../reference/methods#zoomout), [`zoomTo()`](../reference/methods#zoomto) и [`fit()`](../reference/methods#fit) делают то же, что и кнопки, а [`getState()`](../reference/methods#getstate) сообщает текущий масштаб и подгонку:

```ts
pic.fit('width')
pic.zoomTo(2)

const { zoom, fit } = pic.getState()
```
