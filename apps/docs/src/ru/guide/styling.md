# Оформление

PaperPic должен выглядеть частью вашего приложения. Он поставляет одну таблицу стилей, берёт цвета и углы из нескольких CSS-токенов и держит свои правила в каскадном слое, поэтому ваш CSS всегда побеждает.

## Импорт таблицы стилей

Импортируйте её в приложении один раз:

:::tabs key:framework
== JavaScript

```ts
import '@paperpic/core/style.css'
```

== Vue

```ts
import '@paperpic/vue/style.css'
```

== React

```ts
import '@paperpic/react/style.css'
```

:::

## Задать размер

Просмотрщик заполняет свой контейнер и не имеет собственной высоты, поэтому высота нужна контейнеру. Подойдёт любой CSS, который её задаёт:

```css
.document-viewer {
  height: 70dvh;
}
```

Просмотрщик следует размеру контейнера, а не экрана. Он реагирует, когда контейнер меняется, например при открытии боковой панели.

## Цвета и углы

Пять [CSS-токенов](../reference/css-tokens) задают фон, текст, акцентный цвет, радиус углов и длительность переходов. Задавайте их на `:root`, на предке просмотрщика или на `.paperpic`:

```css
:root {
  --paperpic-color-accent: #c2410c;
  --paperpic-radius: 0;
}
```

## Тёмная тема {#dark-mode}

Цвета переключаются на тёмные, когда система пользователя предпочитает тёмную цветовую схему. Если ваш сайт переключает тему иначе, например классом на `<html>`, задайте цвета каждой темы сами:

```css
:root {
  --paperpic-color-surface: #fff;
  --paperpic-color-text: #1a263c;
  --paperpic-color-accent: #0a84ff;
}

:root.dark {
  --paperpic-color-surface: #151e2e;
  --paperpic-color-text: #f2f5f9;
  --paperpic-color-accent: #5cb5ff;
}
```

## Ваш CSS побеждает

Правила PaperPic лежат в каскадном слое `paperpic`, и любой CSS вне слоя их переопределяет, какой бы ни была его специфичность. Это упрощает настройку, но глобальный сброс вне слоя, например правило для `button`, тоже затрагивает кнопки просмотрщика.

Если ваш сброс ломает просмотрщик, перенесите его в слой, который идёт перед `paperpic`. Первое объявление со списком слоёв задаёт их порядок, поэтому разместите его в CSS, который загружается раньше таблицы стилей PaperPic:

```css
@layer reset, paperpic;

@layer reset {
  button {
    all: unset;
  }
}
```

## Расположение

Интерфейс сам подстраивается под контейнер:

- Панель инструментов находится справа и прокручивается, если просмотрщик слишком низкий для её кнопок.
- Панель редактирования находится внизу, в одну строку, или в две, если просмотрщик уже 28rem.
- На сенсорных экранах кнопки и угловые маркеры не меньше 44 пикселей.

## Имена классов

Все классы компонента начинаются с `paperpic`, и их имена стабильны, так что их можно использовать в селекторах. Если токенов хватает для задачи, используйте их, потому что они продолжат работать при изменении внутренней структуры.
