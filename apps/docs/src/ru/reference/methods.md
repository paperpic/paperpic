# Методы

Методы управляют просмотрщиком из вашего кода, например из собственных кнопок с [`toolbar: false`](./options#toolbar). В Vue и React просмотрщик доступен через ref компонента: см. [Vue](./vue) и [React](./react).

```ts
import { PaperPic } from '@paperpic/core'

const pic = new PaperPic(container, { src: '/receipt.jpg' })

pic.zoomIn()
```

## Создание и удаление

### `new PaperPic()`

```ts
class PaperPic {
  constructor(container: HTMLElement, options?: PaperPicOptions)
}
```

Создаёт просмотрщик внутри `container` и заполняет его. Задайте контейнеру высоту, иначе просмотрщик останется минимальной высоты. [Опции](./options) описывают, что принимает `options`.

Выбрасывает `TypeError`, если `container` не элемент. Создавайте просмотрщик, когда элемент уже существует, например при монтировании.

### `destroy()`

```ts
function destroy(): void
```

Удаляет просмотрщик и освобождает всё, что он занимает, например worker и память изображений. Повторный вызов безопасен.

## Опции и состояние

### `setOptions()`

```ts
function setOptions(options: PaperPicOptions): void
```

Меняет переданные опции и сохраняет остальные. `undefined` возвращает опции значение по умолчанию. Никогда не вызывает `change`, поэтому двусторонние привязки не зацикливаются.

### `getState()`

```ts
function getState(): PaperPicState
```

Возвращает то, что показывает просмотрщик, например масштаб, режим и есть ли изменения для применения. [Состояние](./state) описывает каждое поле.

### `on()`

```ts
function on(name: keyof PaperPicEvents, listener: (payload) => void): () => void
```

Подписывается на событие и возвращает функцию, которая отменяет подписку. [События](./events) описывают каждое событие.

```ts
const off = pic.on('apply', ({ blob }) => upload(blob))

off()
```

## Просмотр

### `zoomIn()`

```ts
function zoomIn(): void
```

Увеличивает масштаб на один шаг вокруг центра просмотрщика.

### `zoomOut()`

```ts
function zoomOut(): void
```

Уменьшает масштаб на один шаг вокруг центра просмотрщика.

### `zoomTo()`

```ts
function zoomTo(zoom: number, point?: { x: number, y: number }): void
```

Задаёт масштаб, где `1` показывает один пиксель изображения на пиксель экрана. `point` остаётся на месте: он задаётся в CSS-пикселях от верхнего левого угла просмотрщика и по умолчанию равен его центру.

Масштаб идёт от подгонки всего изображения, или `1`, если это меньше, до `8`. Значение вне диапазона ограничивается.

### `fit()`

```ts
function fit(fit: 'image' | 'width' | 'height'): void
```

Подгоняет под просмотрщик всё изображение, его ширину или его высоту.

## Редактирование

### `edit()`

```ts
function edit(): void
```

Начинает редактирование. Ничего не делает, если изображение не готово или [`editable`](./options#editable) равно `false`.

### `rotate()`

```ts
function rotate(direction?: 1 | -1): void
```

Поворачивает изображение на четверть оборота: по часовой стрелке с `1`, значением по умолчанию, и против часовой с `-1`. Во время редактирования это изменение, которое [`apply()`](#apply) делает постоянным. В просмотрщике только для чтения меняет только отображение. В остальных случаях ничего не делает.

### `flip()`

```ts
function flip(): void
```

Отражает изображение слева направо так, как оно показано, поэтому после четверти оборота оно всё равно отражается слева направо. Чтобы перевернуть изображение вверх ногами, отразите его и поверните дважды. Это изменение, и вне режима редактирования или с открытым инструментом метод ничего не делает.

### `openTool()`

```ts
function openTool(id: ToolId): void
```

Открывает «Обрезать» с `'crop'` или «Выровнять» с `'perspective'`: инструменты с собственным выделением. Инструмент остаётся открытым до [`confirmTool()`](#confirmtool) или [`cancelTool()`](#canceltool), а пока он открыт, остальные изменения, отмена, повтор и применение ничего не делают. Вне режима редактирования ничего не делает.

### `confirmTool()`

```ts
function confirmTool(): void
```

Закрывает открытый инструмент и добавляет его выделение к изменениям, как `Enter`.

### `cancelTool()`

```ts
function cancelTool(): void
```

Закрывает открытый инструмент и отбрасывает его выделение, как `Esc`.

### `setThreshold()`

```ts
function setThreshold(setting: { enabled?: boolean, sensitivity?: number }): void
```

Включает или выключает «Очистить» или меняет его чувствительность от 0 до 1. «Очистить» всегда выполняется после остальных изменений. Вне режима редактирования или с открытым инструментом ничего не делает.

Выбрасывает `RangeError`, если `sensitivity` не от 0 до 1.

### `setAdjustments()`

```ts
function setAdjustments(setting: { brightness?: number, contrast?: number }): void
```

Меняет яркость или контрастность, каждую от -1 до 1, где 0 оставляет изображение как есть. Они выполняются после остальных изменений. Ничего не делает вне режима редактирования, с открытым инструментом или при включённом «Очистить», потому что у очищенного документа свои тона.

Выбрасывает `RangeError`, если значение не от -1 до 1.

### `undo()`

```ts
function undo(): void
```

Отменяет последнее изменение.

### `redo()`

```ts
function redo(): void
```

Возвращает последнее отменённое изменение.

### `apply()`

```ts
function apply(): Promise<void>
```

Применяет изменения в полном разрешении или в [`maxOutputSize`](./options#maxoutputsize). Результат становится изображением на экране, история очищается, просмотрщик возвращается в режим просмотра, а событие [`apply`](./events#apply) передаёт результат. Применение нельзя прервать, и пока оно идёт, элементы управления заблокированы.

При ошибке событие [`error`](./events#error) сообщает о ней, а редактирование остаётся открытым.

### `cancel()`

```ts
function cancel(): void
```

Отменяет изменения и возвращается в режим просмотра. Ничего не спрашивает: это делают встроенная кнопка «Отмена» и `Esc`.

## Изображение

### `download()`

```ts
function download(): void
```

Сохраняет изображение на экране в файл: результат последнего применения или, если его нет, исходное изображение. Работает и без опции [`download`](./options#download), которая только показывает кнопку. Событие [`download`](./events#download) приходит раньше и может отменить сохранение. Во время редактирования ничего не делает, потому что изменения ещё не применены.

### `reload()`

```ts
function reload(): void
```

Заново загружает текущий [`src`](./options#src), что возвращает оригинал после применения.
