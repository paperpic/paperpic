# Методы

Методы управляют просмотрщиком из вашего кода, например из собственных кнопок с [`toolbar: false`](./options#toolbar). С core вызывайте их на созданном вами `PaperPic`. В Vue компонент предоставляет просмотрщик как `instance`, а в React его получает `ref`. Оба равны `null`, пока компонент не смонтирован:

:::tabs key:framework
== JavaScript

```ts
import { PaperPic } from '@paperpic/core'

const pic = new PaperPic(container, { src: '/receipt.jpg' })

pic.zoomIn()
```

== Vue

```vue
<script setup lang="ts">
import { PaperPic } from '@paperpic/vue'
import { useTemplateRef } from 'vue'

const pic = useTemplateRef('pic')
</script>

<template>
  <button type="button" @click="pic?.instance?.zoomIn()">
    Увеличить
  </button>
  <div style="height: 480px">
    <PaperPic ref="pic" src="/receipt.jpg" />
  </div>
</template>
```

== React

```tsx
import type { PaperPicInstance } from '@paperpic/react'
import { PaperPic } from '@paperpic/react'
import { useRef } from 'react'

export function Receipt() {
  const picRef = useRef<PaperPicInstance>(null)

  return (
    <>
      <button type="button" onClick={() => picRef.current?.zoomIn()}>Увеличить</button>
      <div style={{ height: 480 }}>
        <PaperPic ref={picRef} src="/receipt.jpg" />
      </div>
    </>
  )
}
```

:::

В Vue и React компонент сам создаёт и уничтожает просмотрщик, а опции получает как props и события — как собственные события. Поэтому там не вызывайте [`new PaperPic()`](#new-paperpic), [`destroy()`](#destroy), [`setOptions()`](#setoptions) и [`on()`](#on).

## Создание и удаление

### `new PaperPic()`

```ts
class PaperPic {
  constructor(container: HTMLElement, options?: PaperPicOptions)
}
```

Создаёт просмотрщик внутри `container` и заполняет его. Задайте контейнеру высоту, иначе просмотрщик останется минимальной высоты. [Опции](./options) описывают, что принимает `options`.

Выбрасывает `TypeError`, если `container` не элемент. Создавайте просмотрщик, когда элемент уже существует, например при монтировании. Выбрасывает `RangeError`, если опция вне своего диапазона.

Только с core: компоненты для Vue и React создают просмотрщик при монтировании.

### `destroy()`

```ts
function destroy(): void
```

Удаляет просмотрщик и освобождает всё, что он занимает, например worker и память изображений. Повторный вызов безопасен.

Только с core: компоненты для Vue и React вызывают его при размонтировании. Вызванный на их просмотрщике, он оставил бы компонент пустым.

## Опции и состояние

### `setOptions()`

```ts
function setOptions(options: PaperPicOptions): void
```

Меняет переданные опции и сохраняет остальные. `undefined` возвращает опции значение по умолчанию. Никогда не вызывает `change`, поэтому двусторонние привязки не зацикливаются. Выбрасывает `RangeError`, если опция вне своего диапазона, и тогда ни одна опция не меняется.

В Vue и React вместо этого меняйте props. Следующее изменение любого prop снова передаёт все опции и отменило бы изменение, сделанное через `setOptions()`.

### `getState()`

```ts
function getState(): PaperPicState
```

Возвращает текущее состояние просмотрщика, например масштаб, режим и есть ли изменения для применения. Чтобы узнавать о каждом изменении, не спрашивая, слушайте [`change`](./events#change). [Состояние](./state) описывает каждое поле и то, как они работают вместе.

### `on()`

```ts
function on<Name extends keyof PaperPicEvents>(name: Name, listener: (payload: PaperPicEvents[Name]) => void): () => void
```

Подписывается на событие и возвращает функцию, которая отменяет подписку. [События](./events) описывают каждое событие.

```ts
const off = pic.on('apply', ({ blob }) => upload(blob))

off()
```

В Vue и React вместо этого слушайте события компонента, например `@apply` или `onApply`.

## Просмотр

### `zoomIn()`

```ts
function zoomIn(): void
```

Увеличивает масштаб на один шаг вокруг центра просмотрщика.

### `zoomOut()`

```ts
function zoomOut(): void
```

Уменьшает масштаб на один шаг вокруг центра просмотрщика.

### `zoomTo()`

```ts
function zoomTo(zoom: number, point?: ViewPoint): void
```

Задаёт масштаб, где `1` показывает один пиксель изображения на пиксель экрана. [`point`](./types#viewpoint) остаётся на месте: он задаётся в CSS-пикселях от верхнего левого угла просмотрщика и по умолчанию равен его центру.

Масштаб идёт от подгонки всего изображения, или `1`, если это меньше, до `8`. Значение вне диапазона ограничивается.

Выбрасывает `RangeError`, если `zoom` равен `NaN` или координата `point` не является конечным числом, и тогда масштаб не меняется.

### `fit()`

```ts
function fit(fit: Fit): void
```

Подгоняет под просмотрщик всё изображение, его ширину или его высоту. `fit` — это [`Fit`](./types#fit): `'image'`, `'width'` или `'height'`.

## Редактирование

### `edit()`

```ts
function edit(): void
```

Начинает редактирование. Ничего не делает, если изображение не готово или [`editable`](./options#editable) равно `false`.

### `rotate()`

```ts
function rotate(direction?: 1 | -1): void
```

Поворачивает изображение на четверть оборота: по часовой стрелке с `1`, значением по умолчанию, и против часовой с `-1`. Во время редактирования добавляет изменение, которое [`apply()`](#apply) делает постоянным, и ничего не делает, пока открыт инструмент или идёт применение. В просмотрщике только для чтения меняет только отображение. В остальных случаях ничего не делает.

### `flip()`

```ts
function flip(): void
```

Отражает изображение слева направо так, как оно показано, поэтому после четверти оборота оно всё равно отражается слева направо. Чтобы отразить изображение сверху вниз, отразите его и поверните дважды. Это изменение, и вне режима редактирования или с открытым инструментом метод ничего не делает.

### `openTool()`

```ts
function openTool(id: ToolId): void
```

Открывает инструмент с элементами управления на панели: «Обрезать» (`'crop'`), «Выровнять» (`'perspective'`), «Настроить» (`'adjust'`) или «Очистить» (`'threshold'`), который включается при открытии. Инструмент остаётся открытым до [`confirmTool()`](#confirmtool) или [`cancelTool()`](#canceltool). Пока он открыт, другое изменение начать нельзя, а отмена, повтор и применение ничего не делают. Ничего не делает вне режима редактирования, при другом открытом инструменте, для «Настроить» при включённом «Очистить» и для «Обрезать» и «Выровнять», пока готовится предпросмотр.

### `confirmTool()`

```ts
function confirmTool(): void
```

Закрывает открытый инструмент и добавляет к изменениям то, что в нём выбрано, как `Enter`: выделение «Обрезать» или «Выровнять» либо настройки «Настроить» или «Очистить» как одно изменение.

### `cancelTool()`

```ts
function cancelTool(): void
```

Закрывает открытый инструмент и отбрасывает его изменения, как `Esc`.

### `setThreshold()`

```ts
function setThreshold(setting: { enabled?: boolean, sensitivity?: number }): void
```

Включает или выключает «Очистить» или меняет его чувствительность от 0 до 1. «Очистить» всегда выполняется после остальных изменений. Пока «Очистить» открыт, меняет то, что он показывает, а [`confirmTool()`](#confirmtool) сохраняет это как одно изменение. Вне режима редактирования или при другом открытом инструменте ничего не делает.

Выбрасывает `RangeError`, если `sensitivity` не от 0 до 1.

### `setAdjustments()`

```ts
function setAdjustments(setting: { brightness?: number, contrast?: number }): void
```

Меняет яркость или контрастность, каждую от -1 до 1, где 0 оставляет изображение как есть. Они выполняются после остальных изменений. Пока «Настроить» открыт, меняет то, что он показывает, а [`confirmTool()`](#confirmtool) сохраняет это как одно изменение. Ничего не делает вне режима редактирования, при другом открытом инструменте или при включённом «Очистить»: «Очистить» сравнивает каждый пиксель с его окружением, поэтому яркость и контрастность почти не изменили бы результат.

Выбрасывает `RangeError`, если значение не от -1 до 1.

### `undo()`

```ts
function undo(): void
```

Отменяет последнее изменение. Ничего не делает вне режима редактирования, при открытом инструменте или пока идёт применение.

### `redo()`

```ts
function redo(): void
```

Возвращает последнее отменённое изменение. Ничего не делает вне режима редактирования, при открытом инструменте или пока идёт применение.

### `apply()`

```ts
function apply(): Promise<void>
```

Применяет изменения в полном разрешении или в [`maxOutputSize`](./options#maxoutputsize). Результат становится изображением на экране, история очищается, просмотрщик возвращается в режим просмотра, а событие [`apply`](./events#apply) передаёт результат. Применение нельзя прервать, и пока оно идёт, элементы управления заблокированы. Ничего не делает вне режима редактирования, при открытом инструменте или когда применять нечего.

При ошибке событие [`error`](./events#error) сообщает о ней, а редактирование остаётся открытым. Промис выполняется, когда применение заканчивается, даже при ошибке: слушайте `error`, потому что `try/catch` её не поймает.

### `cancel()`

```ts
function cancel(): void
```

Отменяет изменения и возвращается в режим просмотра. Ничего не спрашивает: это делают встроенная кнопка «Отмена» и `Esc`. Ничего не делает, пока идёт применение.

## Изображение

### `download()`

```ts
function download(): void
```

Сохраняет изображение на экране в файл: результат последнего применения или, если его нет, исходное изображение. Работает и без опции [`download`](./options#download), которая только показывает кнопку. Событие [`download`](./events#download) приходит раньше и может отменить сохранение. Во время редактирования ничего не делает, потому что изменения ещё не применены. До первого применения `src` с другого источника вместо этого открывается в браузере: см. [Сохранение результата](../guide/saving#download).

### `reload()`

```ts
function reload(): void
```

Заново загружает текущий [`src`](./options#src), что возвращает оригинал после применения. Во время редактирования отбрасывает изменения. Без `src` ничего не делает.
