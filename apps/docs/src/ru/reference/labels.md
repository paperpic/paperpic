# Подписи

Подписи — это тексты, которые компонент показывает, и те, что он озвучивает программам чтения с экрана. По умолчанию они на английском. Передайте те, что хотите изменить, в опцию [`labels`](./options#labels), а остальные сохранят английский текст.

```ts
const pic = new PaperPic(container, {
  src: '/receipt.jpg',
  labels: {
    apply: 'Применить',
    cancel: 'Отмена',
    zoomLevel: percent => `Масштаб ${percent} %`,
  },
})
```

Пять подписей — функции, потому что их текст содержит значение. Создайте объект один раз, а не при каждом рендере, чтобы просмотрщик не получал его заново каждый раз.

| Ключ                   | Английский                                   | Где используется                                                                                                     |
| ---------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `adjust`               | Adjust                                       | Кнопка, которая открывает шкалу яркости и контрастности                                                              |
| `adjustmentLevel`      | Brightness +30                               | Функция имени и значения от -100 до 100, озвучивается после перемещения шкалы «Настроить»                            |
| `applied`              | Changes applied                              | Озвучивается, когда изменения применены                                                                              |
| `apply`                | Apply                                        | Кнопка, которая применяет изменения                                                                                  |
| `applyError`           | The changes could not be applied             | Показывается, когда применение не удалось                                                                            |
| `brightness`           | Brightness                                   | Выбор яркости в «Настроить» и название её шкалы                                                                      |
| `cancel`               | Cancel                                       | Кнопка, которая выходит из режима редактирования                                                                     |
| `cancelTool`           | Cancel this tool                             | Кнопка, которая закрывает инструмент и отбрасывает его изменения                                                     |
| `confirm`              | Done                                         | Кнопка, которая закрывает инструмент и сохраняет его изменения                                                       |
| `contrast`             | Contrast                                     | Выбор контрастности в «Настроить» и название её шкалы                                                                |
| `cornerBottomLeft`     | Bottom left corner                           | Название углового маркера                                                                                            |
| `cornerBottomRight`    | Bottom right corner                          | Название углового маркера                                                                                            |
| `cornerMoved`          | Top left corner: 120, 80                     | Функция угла и его позиции в пикселях изображения, озвучивается после перемещения угла                               |
| `cornerSelected`       | Top left corner: tap where it goes           | Функция угла, показывается и озвучивается после нажатия углового маркера, пока касание изображения не переместит его |
| `cornerTopLeft`        | Top left corner                              | Название углового маркера                                                                                            |
| `cornerTopRight`       | Top right corner                             | Название углового маркера                                                                                            |
| `crop`                 | Crop                                         | Кнопка «Обрезать»                                                                                                    |
| `cropHint`             | Drag the corners                             | Что делать в «Обрезать»                                                                                              |
| `discard`              | Discard                                      | Кнопка, которая подтверждает потерю изменений                                                                        |
| `discardQuestion`      | Discard your changes?                        | Вопрос перед потерей изменений                                                                                       |
| `download`             | Download                                     | Кнопка скачивания                                                                                                    |
| `edit`                 | Edit                                         | Кнопка, которая начинает редактирование                                                                              |
| `editBar`              | Editing controls                             | Название панели редактирования для программ чтения с экрана                                                          |
| `editing`              | Editing                                      | Озвучивается, когда начинается режим редактирования                                                                  |
| `fitHeight`            | Fit to height                                | Кнопка, которая подгоняет изображение по высоте                                                                      |
| `fitWidth`             | Fit to width                                 | Кнопка, которая подгоняет изображение по ширине                                                                      |
| `flip`                 | Flip                                         | Кнопка «Отразить»                                                                                                    |
| `inUse`                | In use                                       | Описание «Настроить» или «Очистить», пока их настройка действует, что показывает точка                               |
| `keepEditing`          | Keep editing                                 | Кнопка, которая возвращает к редактированию вместо потери изменений                                                  |
| `loadError`            | The image could not be loaded                | Показывается, когда изображение не загрузилось                                                                       |
| `loading`              | Loading image                                | Показывается, пока изображение загружается                                                                           |
| `perspective`          | Straighten                                   | Кнопка «Выровнять»                                                                                                   |
| `perspectiveHint`      | Drag each corner to a corner of the document | Что делать в «Выровнять»                                                                                             |
| `processing`           | Applying changes                             | Показывается, пока идёт применение                                                                                   |
| `redo`                 | Redo                                         | Кнопка «Повторить»                                                                                                   |
| `rotateLeft`           | Rotate left                                  | Кнопка поворота на панели редактирования и одна из двух в просмотрщике только для чтения                             |
| `rotateRight`          | Rotate right                                 | Другая кнопка поворота в просмотрщике только для чтения                                                              |
| `threshold`            | Clean up                                     | Кнопка «Очистить» и переключатель, который его включает и выключает                                                  |
| `thresholdLevel`       | Sensitivity 50%                              | Функция процента, озвучивается после перемещения шкалы «Очистить»                                                    |
| `thresholdSensitivity` | Sensitivity                                  | Название шкалы «Очистить»                                                                                            |
| `toolbar`              | Image controls                               | Название панели инструментов для программ чтения с экрана                                                            |
| `undo`                 | Undo                                         | Кнопка «Отменить»                                                                                                    |
| `viewer`               | Image viewer                                 | Название области, где показано изображение, для программ чтения с экрана                                             |
| `zoomIn`               | Zoom in                                      | Кнопка «Увеличить» на панели инструментов и в элементах управления «Обрезать» и «Выровнять»                          |
| `zoomLevel`            | Zoom 150%                                    | Функция процента, озвучивается после масштабирования с панели инструментов или клавиатуры                            |
| `zoomOut`              | Zoom out                                     | Кнопка «Уменьшить» на панели инструментов и в элементах управления «Обрезать» и «Выровнять»                          |
