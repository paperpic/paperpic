# CSS-токены

Токены — это пользовательские свойства CSS, которые меняют вид компонента, не переопределяя его правила. Задавайте их на `:root`, на предке просмотрщика или на `.paperpic`:

```css
:root {
  --paperpic-color-accent: #c2410c;
  --paperpic-radius: 0;
}
```

| Токен                            | По умолчанию | Тёмная тема | Описание                          |
| -------------------------------- | ------------ | ----------- | --------------------------------- |
| `--paperpic-color-accent`        | `#0a84ff`    | `#5cb5ff`   | Акцентный цвет интерфейса         |
| `--paperpic-color-surface`       | `#fff`       | `#151e2e`   | Фон интерфейса                    |
| `--paperpic-color-text`          | `#1a263c`    | `#f2f5f9`   | Текст интерфейса                  |
| `--paperpic-radius`              | `6px`        | `6px`       | Радиус углов интерфейса           |
| `--paperpic-transition-duration` | `0.2s`       | `0.2s`      | Длительность переходов интерфейса |

## Тёмная тема

Тёмные значения действуют, когда система пользователя предпочитает тёмную цветовую схему. Если ваш сайт переключает тему иначе, например классом на `<html>`, задайте цвета каждой темы сами:

```css
:root {
  --paperpic-color-surface: #fff;
  --paperpic-color-text: #1a263c;
  --paperpic-color-accent: #0a84ff;
}

:root.dark {
  --paperpic-color-surface: #151e2e;
  --paperpic-color-text: #f2f5f9;
  --paperpic-color-accent: #5cb5ff;
}
```

## Таблица стилей

Каждый пакет поставляет одну таблицу стилей. Импортируйте её в приложении один раз:

:::tabs key:framework
== JavaScript

```ts
import '@paperpic/core/style.css'
```

== Vue

```ts
import '@paperpic/vue/style.css'
```

== React

```ts
import '@paperpic/react/style.css'
```

:::

Её правила лежат в каскадном слое `paperpic`, поэтому любой ваш CSS вне слоя переопределяет их, какой бы ни была его специфичность. Это касается и глобальных сбросов, например правила для `button`.

## Имена классов

`.paperpic` — корень просмотрщика, а `.paperpic-host` — элемент, который компоненты Vue и React создают вокруг него. Все классы компонента начинаются с `paperpic`, и их имена стабильны. Если токенов хватает для задачи, используйте их.
