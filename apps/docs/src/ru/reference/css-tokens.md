# CSS-токены

Токены — это пользовательские свойства CSS, которые меняют вид компонента, не переопределяя его правила. Задавайте их на `:root`, на предке просмотрщика или на `.paperpic`:

```css
:root {
  --paperpic-color-accent: #c2410c;
  --paperpic-radius: 0;
}
```

| Токен                            | Светлая   | Тёмная    | Описание                          |
| -------------------------------- | --------- | --------- | --------------------------------- |
| `--paperpic-color-accent`        | `#0a84ff` | `#5cb5ff` | Акцентный цвет интерфейса         |
| `--paperpic-color-surface`       | `#fff`    | `#151e2e` | Фон интерфейса                    |
| `--paperpic-color-text`          | `#1a263c` | `#f2f5f9` | Текст интерфейса                  |
| `--paperpic-radius`              | `6px`     | `6px`     | Радиус углов интерфейса           |
| `--paperpic-transition-duration` | `0.2s`    | `0.2s`    | Длительность переходов интерфейса |

## Тёмная тема

Цветовые токены берут светлое или тёмное значение через `light-dark()`, по `color-scheme` страницы. Без `color-scheme` они светлые. С `color-scheme: dark` они тёмные, а с `color-scheme: light dark` тёмные, когда система предпочитает тёмную цветовую схему. Как это задать, показывает [Оформление](../guide/styling#dark-mode).

Чтобы выбрать оба значения токена, тоже используйте `light-dark()`:

```css
:root {
  --paperpic-color-accent: light-dark(#c2410c, #fb923c);
}
```

## Таблица стилей

Каждый пакет поставляет одну таблицу стилей. Импортируйте её в приложении один раз:

:::tabs key:framework
== JavaScript

```ts
import '@paperpic/core/style.css'
```

== Vue

```ts
import '@paperpic/vue/style.css'
```

== React

```ts
import '@paperpic/react/style.css'
```

:::

Её правила лежат в каскадном слое `paperpic`, поэтому любой ваш CSS вне слоя переопределяет их, какой бы ни была его специфичность. Это касается и глобальных сбросов, например правила для `button`. С Tailwind CSS перечислите порядок слоёв, как показывает [Оформление](../guide/styling#tailwind).

## Классы {#classes}

Эти классы публичные: их имена и элементы, которые они отмечают, не меняются между версиями. Остальные классы компонента держат его расположение и могут измениться в любой версии.

| Класс                     | Элемент                                                                                                                           |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `paperpic`                | Корень просмотрщика                                                                                                               |
| `paperpic-button`         | Каждая кнопка панели инструментов и панели редактирования                                                                         |
| `paperpic-button-danger`  | Отменить изменения, в вопросе перед отменой изменений                                                                             |
| `paperpic-button-primary` | Применить, а также Готово в инструментах Обрезать и Выровнять                                                                     |
| `paperpic-button-text`    | Кнопки вопроса перед отменой изменений                                                                                            |
| `paperpic-edit-bar`       | Панель редактирования внизу                                                                                                       |
| `paperpic-editing`        | Корень во время редактирования                                                                                                    |
| `paperpic-handle`         | Угловой маркер инструментов Обрезать и Выровнять                                                                                  |
| `paperpic-host`           | Элемент, который компоненты Vue и React создают вокруг просмотрщика                                                               |
| `paperpic-icon`           | Иконка кнопки                                                                                                                     |
| `paperpic-status`         | Сообщение для программ чтения с экрана, которое также видно, пока изображение загружается или изменения применяются, и при ошибке |
| `paperpic-status-visible` | Сообщение, пока оно видно в центре просмотрщика                                                                                   |
| `paperpic-toolbar`        | Панель инструментов справа                                                                                                        |
| `paperpic-viewport`       | Область, которая показывает изображение и получает фокус клавиатуры                                                               |

Кнопки показывают состояние ARIA-атрибутами, которые тоже можно выбирать:

| Атрибут                  | Состояние                                                                                     |
| ------------------------ | --------------------------------------------------------------------------------------------- |
| `[aria-disabled='true']` | Кнопка сейчас не может действовать. Она сохраняет фокус клавиатуры, поэтому она не `disabled` |
| `[aria-expanded='true']` | Настроить, пока видны его ползунки                                                            |
| `[aria-pressed='true']`  | Включённая кнопка, например Очистить или действующие По ширине и По высоте                    |

Наведение и эти состояния рисуются через `box-shadow`, который глобальные сбросы кнопок не трогают. Чтобы изменить их, переопределите и `box-shadow`.

## Элементы управления {#controls}

Каждая кнопка, ползунок и угловой маркер несёт `data-paperpic-control` с ключом своей [подписи](./labels). Выберите его, чтобы оформить один элемент управления:

```css
.paperpic-button[data-paperpic-control='edit'] {
  color: var(--paperpic-color-accent);
}
```

| Место                          | Значения                                                                                              |
| ------------------------------ | ----------------------------------------------------------------------------------------------------- |
| Панель инструментов            | `edit`, `zoomIn`, `zoomOut`, `fitWidth`, `fitHeight`, `rotateLeft`, `rotateRight`, `download`         |
| Панель редактирования          | `cancel`, `crop`, `perspective`, `rotateLeft`, `flip`, `adjust`, `threshold`, `undo`, `redo`, `apply` |
| Ползунки                       | `thresholdSensitivity`, `brightness`, `contrast`                                                      |
| Обрезать и Выровнять           | `cancelTool`, `confirm`, `cornerTopLeft`, `cornerTopRight`, `cornerBottomRight`, `cornerBottomLeft`   |
| Вопрос перед отменой изменений | `keepEditing`, `discard`                                                                              |

`rotateLeft` называет две кнопки, которые никогда не видны одновременно: кнопку просмотрщика только для чтения, которая поворачивает отображение, и кнопку панели редактирования, которая поворачивает само изображение.
