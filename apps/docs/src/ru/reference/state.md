# Состояние

Состояние описывает, что показывает просмотрщик в данный момент. [`getState()`](./methods#getstate) возвращает его, а событие [`change`](./events#change) передаёт. Используйте его, чтобы держать в актуальном виде свои элементы управления, например кнопку «Применить»:

```ts
pic.on('change', ({ canApply, busy }) => {
  applyButton.disabled = !canApply || busy
})
```

| Поле          | Тип                                          | Описание                                                                                              |
| ------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `activeTool`  | `ToolId \| null`                             | Открытый инструмент, `'crop'` или `'perspective'`, или `null`                                         |
| `adjustments` | `{ brightness, contrast }`                   | Яркость и контрастность, каждая от -1 до 1. «Очистить» их не учитывает                                |
| `busy`        | `boolean`                                    | Идёт ли применение                                                                                    |
| `canApply`    | `boolean`                                    | Есть ли изменения для применения. Повороты и отражения, которые компенсируют друг друга, не считаются |
| `canRedo`     | `boolean`                                    | Есть ли изменение для повтора                                                                         |
| `canUndo`     | `boolean`                                    | Есть ли изменение для отмены                                                                          |
| `fit`         | `'image' \| 'width' \| 'height' \| null`     | Действующая подгонка или `null`, как только пользователь масштабировал вручную                        |
| `image`       | `{ width, height } \| null`                  | Размер изображения на экране в пикселях с учётом сделанных изменений или `null` без изображения       |
| `mode`        | `'view' \| 'edit'`                           | Просматривает пользователь изображение или редактирует                                                |
| `rotation`    | `0 \| 90 \| 180 \| 270`                      | Насколько повёрнуто изображение на экране, в градусах по часовой стрелке                              |
| `status`      | `'empty' \| 'loading' \| 'ready' \| 'error'` | Есть ли изображение и загрузилось ли оно                                                              |
| `threshold`   | `{ enabled, sensitivity }`                   | Включено ли «Очистить» и его чувствительность от 0 до 1                                               |
| `zoom`        | `number`                                     | Пиксели экрана на пиксель изображения                                                                 |
