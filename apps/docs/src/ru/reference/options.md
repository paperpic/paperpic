# Опции

Опции задают, что показывает просмотрщик и что пользователь может с ним делать. Передайте их при создании просмотрщика или измените позже через [`setOptions()`](./methods#setoptions). Компоненты Vue и React принимают их как props с теми же именами.

```ts
const pic = new PaperPic(container, { src: '/receipt.jpg', alt: 'Кассовый чек' })

pic.setOptions({ editable: false })
```

`setOptions()` меняет только переданные опции, а `undefined` возвращает опции значение по умолчанию. Метод никогда не вызывает `change`.

## Изображение

### `src`

- **Тип:** `string | Blob`
- **По умолчанию:** нет

Изображение для показа: URL того же источника или `File` либо `Blob`, прикреплённый на клиенте.

Повторная передача того же значения не перезагружает изображение, поэтому результат редактирования остаётся на экране. Вызовите [`reload()`](./methods#reload), чтобы вернуть оригинал. Новое значение во время редактирования отменяет изменения.

### `alt`

- **Тип:** `string`
- **По умолчанию:** `''`

Описывает изображение для программ чтения с экрана.

## Интерфейс

### `editable`

- **Тип:** `boolean`
- **По умолчанию:** `true`

Может ли пользователь редактировать изображение. С `false` это просмотрщик только для чтения, и на его панели инструментов появляются кнопки поворота. Такой поворот меняет только отображение. Изменение этой опции во время редактирования отменяет изменения.

### `toolbar`

- **Тип:** `boolean`
- **По умолчанию:** `true`

Показывать ли встроенные панель инструментов и панель редактирования. Без них создайте свои элементы управления с помощью [методов](./methods).

### `tools`

- **Тип:** `readonly ToolId[]`
- **По умолчанию:** все инструменты

Инструменты, которые предлагает панель редактирования. Они идут в порядке этой таблицы, в каком бы порядке их ни перечислял массив.

| Id              | Кнопка                                 |
| --------------- | -------------------------------------- |
| `'crop'`        | Обрезать                               |
| `'perspective'` | Выровнять                              |
| `'rotate'`      | Повернуть влево                        |
| `'flip'`        | Отразить                               |
| `'adjust'`      | Настроить, для яркости и контрастности |
| `'threshold'`   | Очистить                               |

### `wheelZoom`

- **Тип:** `boolean`
- **По умолчанию:** `true`

Масштабирует ли колесо мыши изображение. Отключите, когда просмотрщик стоит на длинной странице, чтобы колесо прокручивало страницу.

### `download`

- **Тип:** `boolean`
- **По умолчанию:** `false`

Есть ли на панели инструментов кнопка, которая сохраняет изображение на экране: результат последнего применения или, если его нет, исходное изображение. Во время редактирования кнопка скрыта. Событие [`download`](./events#download) позволяет сохранить файл иначе.

### `labels`

- **Тип:** `Partial<PaperPicLabels>`
- **По умолчанию:** тексты на английском

Заменяет любые тексты, которые компонент показывает или озвучивает. [Подписи](./labels) перечисляют все ключи.

### `icons`

- **Тип:** `Partial<PaperPicIcons>`
- **По умолчанию:** встроенные иконки

Заменяет любые иконки вашей разметкой из одного элемента, например `<svg>`. Разметка попадает на страницу как HTML, поэтому передавайте только разметку, которой доверяете. Пустая строка оставляет кнопки этой иконки без неё. Пример показывает [Оформление](../guide/styling#icons).

Каждый ключ называет иконку, и некоторые иконки есть на двух кнопках:

| Ключ             | Кнопка                                                                  |
| ---------------- | ----------------------------------------------------------------------- |
| `adjust`         | Настроить                                                               |
| `apply`          | Применить, а также Готово в инструментах Обрезать и Выровнять           |
| `cancel`         | Отмена, а также Отменить этот инструмент                                |
| `crop`           | Обрезать                                                                |
| `download`       | Скачать                                                                 |
| `edit`           | Редактировать                                                           |
| `fitHeight`      | По высоте                                                               |
| `fitWidth`       | По ширине                                                               |
| `flip`           | Отразить                                                                |
| `perspective`    | Выровнять                                                               |
| `redo`           | Повторить                                                               |
| `rotateDocument` | Повернуть влево, на панели редактирования                               |
| `rotateLeft`     | Повернуть влево, на панели инструментов просмотрщика только для чтения  |
| `rotateRight`    | Повернуть вправо, на панели инструментов просмотрщика только для чтения |
| `threshold`      | Очистить                                                                |
| `undo`           | Отменить                                                                |
| `zoomIn`         | Увеличить                                                               |
| `zoomOut`        | Уменьшить                                                               |

## Результат

### `output`

- **Тип:** `{ type?: string, quality?: number }`
- **По умолчанию:** формат исходного изображения

Формат отредактированного изображения. `type` — это `'image/jpeg'`, `'image/png'` или `'image/webp'`, а `quality` — от 0 до 1 для JPEG и WebP, по умолчанию `0.92`.

Без `type` очищенное изображение сохраняется в PNG, потому что JPEG испортил бы его чёткие края, а любое другое изображение сохраняет формат оригинала. Формат, который браузер не умеет кодировать, даёт PNG.

### `maxOutputSize`

- **Тип:** `number`
- **По умолчанию:** полное разрешение

Длинная сторона отредактированного изображения в пикселях. Результат большего размера уменьшается.

### `filename`

- **Тип:** `string`
- **По умолчанию:** имя исходного изображения

Имя сохраняемого файла. Его расширение следует формату изображения, поэтому очищенный `receipt.jpg` сохраняется как `receipt.png`. Если у исходного изображения нет имени, как у `Blob`, файл называется `image`.

## Инструменты

### `aspectRatio`

- **Тип:** `number`
- **По умолчанию:** оцениваются

Реальные пропорции документа как ширина, делённая на высоту, например `210 / 297` для листа A4. Инструмент «Выровнять» придаёт результату эти пропорции. Без них он оценивает пропорции по фотографии.

### `softness`

- **Тип:** `number`, от 0 до 1
- **По умолчанию:** `0.25`

Сколько серого «Очистить» оставляет по краям букв, чтобы их было легче читать. Используйте `0` для строгого чёрно-белого, которое даёт файлы меньше, но ломает тонкие штрихи.
