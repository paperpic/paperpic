# Glossary: 한국어

Use these words in the Korean docs, so that each idea has one name on every page. Name the controls of the component exactly as [`paperpic-labels.ts`](../.vitepress/theme/components/paperpic-labels.ts) labels them in Korean, such as "적용" for Apply. [Translating the docs](../../../.github/CONTRIBUTING.md#translating-the-docs) has the other rules.

| CSS token                                     | CSS 토큰       |

| dot, the mark of a tool in use                | 점             |

| event                                         | 이벤트         |
| guide                                         | 가이드         |
| keyboard shortcut                             | 키보드 단축키  |
| label, a text of the interface                | 레이블         |
| magnifier                                     | 돋보기         |
| method                                        | 메서드         |
| option                                        | 옵션           |
| pan, move a zoomed image                      | 이동           |
| panel, the controls of an open tool           | 패널           |
| parent element                                | 부모 요소      |
