# Glossary: Português (Brasil)

Use these words in the Portuguese docs, so that each idea has one name on every page. Name the controls of the component exactly as [`paperpic-labels.ts`](../.vitepress/theme/components/paperpic-labels.ts) labels them in Portuguese, such as "Aplicar" for Apply. [Translating the docs](../../../.github/CONTRIBUTING.md#translating-the-docs) has the other rules.
