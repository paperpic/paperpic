Export every type of `@paperpic/core`, so you never need to install it to type your code. The new ones are `Fit`, `PaperPicOptions`, `PaperPicSource`, `Rotation`, `Size` and `ViewPoint`. `@paperpic/vue` also exports `PaperPicInstance`, the type of the `instance` that the component exposes.
